# Настройка репозиториев

> Здесь хранилища TACTIC сопоставляются с путями, доступными на этом компьютере. От этих путей
> зависят снапшоты, превью, Check-in, Check-out и синхронизация репозитория.

## Хранилище репозитория

Карточка состояния показывает текущий репозиторий по умолчанию и его путь для запущенной платформы.
**Требуется настройка** означает, что рабочего пути по умолчанию нет; **Настроено** — что текущее
сопоставление можно использовать; **Загрузка** — что определения репозиториев ещё читаются с сервера.

| Кнопка или область | Что делает |
| --- | --- |
| **Открыть редактор репозиториев** | Открывает все определения репозиториев для редактирования. |
| **Проверить пути** | Создаёт отсутствующие каталоги включённых репозиториев текущей платформы, затем проверяет доступ. При неудаче показывает ошибку файловой системы. Пустые пути не принимаются. |
| **Активные репозитории** | Показывает включённые репозитории, их коды TACTIC, пути текущей платформы, метку репозитория по умолчанию и результат последней проверки. |

## Поля редактора репозиториев

Local по умолчанию выключен в новых настройках репозиториев. Сохранённый выбор пользователя не меняется.

| Поле | Значение |
| --- | --- |
| **Добавить пользовательский репозиторий** | Добавляет локальный черновик репозитория. Серверные определения остаются без изменений. |
| **Включён** | Делает расположение доступным файловым операциям и спискам выбора репозитория. |
| **По умолчанию** | Используется, если операция явно не выбрала другое назначение. Репозиторий по умолчанию должен быть один и быть включён. |
| **Отображаемое имя** | Видимая подпись пользовательского репозитория. Не заменяет нативный серверный код. |
| **Путь Windows / путь Linux** | Абсолютные платформенные корни одного и того же репозитория TACTIC. Указывайте только реальные пути к этому хранилищу. |
| **Удалить пользовательский репозиторий** | Удаляет только выбранный пользовательский черновик; встроенные серверные определения здесь удалить нельзя. |
| **Привязки проектов** | Показывают проекты и серверные определения, использующие расположение. Это диагностика, а не локальные названия для исправления. |
| **Сохранить / Отмена** | Сохранение записывает пути в активный серверный пресет; отмена закрывает редактор без записи черновиков. |

Если у активного серверного пресета нет рабочего репозитория по умолчанию, TACTIC Handler один раз
за запуск предлагает открыть эту страницу. Кнопка **Позже** только откладывает настройку и не
помечает репозиторий настроенным.

## Ожидание настройки репозитория

Если локальный корень репозитория пустой, относительный или недоступен, фоновые
превью и синхронизация ждут настройки репозитория. HTTP-загрузка и автоматическое
создание корневой папки не запускаются; такое ожидание не добавляет повторные
ошибки скачивания в уведомления и Debug Log. Другие доступные репозитории
продолжают работать.

Откройте **Редактор репозиториев**, укажите абсолютный локальный путь и сохраните
его. Кнопка **Проверить пути** позволяет явно создать и проверить папку. После
применения конфигурации превью запрашиваются с актуальными путями, а ожидающие
загрузки очереди продолжаются с прежними объектами файлов. Обычное обновление
списка или повтор загрузки не проверяют недоступный корень заново до применения
конфигурации репозитория. Настоящие ошибки передачи при доступном корне остаются
видимыми.

## Локальный путь и сохранение

Серверный путь `/opt/...` — настройка хранения на сервере, а не локальная папка
Windows. ТХ сохраняет рабочие локальные пути при перечитывании настроек;
несовместимый серверный путь не подставляется в качестве локального. Пока папка
не настроена, превью показывает обычную заглушку без бесконечной анимации загрузки.

На Windows измените **Путь Windows** в редакторе репозиториев, выберите нужный
пункт **По умолчанию** и нажмите **Сохранить**. Проверка и создание введённой
папки выполняются в фоне, окно остаётся доступным. Проверяются изменённые или
включённые пути и выбранный репозиторий по умолчанию. Другой неизменённый
недоступный путь не мешает сохранить тот, который вы настраиваете. При ошибке
создания или доступа сохраняется прежняя настройка, а редактор показывает причину.
Запись настроек происходит после проверки и сохраняется после перезапуска.
Отдельно нажимать **Проверить пути** перед сохранением не обязательно.
