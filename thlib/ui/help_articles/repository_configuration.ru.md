# Настройка репозиториев

> Здесь хранилища TACTIC сопоставляются с путями, доступными на этом компьютере. От этих путей
> зависят снапшоты, превью, Check-in, Check-out и синхронизация репозитория.

## Хранилище репозитория

Карточка состояния показывает текущий репозиторий по умолчанию и его путь для запущенной платформы.
**Требуется настройка** означает, что рабочего пути по умолчанию нет; **Настроено** — что текущее
сопоставление можно использовать; **Загрузка** — что определения репозиториев ещё читаются с сервера.

| Кнопка или область | Что делает |
| --- | --- |
| **Открыть редактор репозиториев** | Открывает все определения репозиториев для редактирования. |
| **Проверить пути** | Проверяет все включённые пути текущей платформы и обновляет их состояние. Отсутствующие каталоги не создаются. |
| **Активные репозитории** | Показывает включённые репозитории, их коды TACTIC, пути текущей платформы, метку репозитория по умолчанию и результат последней проверки. |

## Поля редактора репозиториев

| Поле | Значение |
| --- | --- |
| **Добавить пользовательский репозиторий** | Добавляет локальный черновик репозитория. Серверные определения остаются без изменений. |
| **Включён** | Делает расположение доступным файловым операциям и спискам выбора репозитория. |
| **По умолчанию** | Используется, если операция явно не выбрала другое назначение. Репозиторий по умолчанию должен быть один и быть включён. |
| **Отображаемое имя** | Видимая подпись пользовательского репозитория. Не заменяет нативный серверный код. |
| **Путь Windows / путь Linux** | Абсолютные платформенные корни одного и того же репозитория TACTIC. Указывайте только реальные пути к этому хранилищу. |
| **Удалить пользовательский репозиторий** | Удаляет только выбранный пользовательский черновик; встроенные серверные определения здесь удалить нельзя. |
| **Привязки проектов** | Показывают проекты и серверные определения, использующие расположение. Это диагностика, а не локальные названия для исправления. |
| **Сохранить / Отмена** | Сохранение записывает пути в активный серверный пресет; отмена закрывает редактор без записи черновиков. |

Если у активного серверного пресета нет рабочего репозитория по умолчанию, TACTIC Handler один раз
за запуск предлагает открыть эту страницу. Кнопка **Позже** только откладывает настройку и не
помечает репозиторий настроенным.
