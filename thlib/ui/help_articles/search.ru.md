# Поиск и фильтры

> Одна вкладка поиска — это самостоятельный запрос со своими условиями, видом результатов,
> сортировкой, группировкой, загруженными страницами и позицией прокрутки.

## Из чего складывается запрос

Поиск можно собирать слоями. Все слои в итоге видны как условия в **Расширенном поиске**:

```text
Текст из верхней строки
    AND выбранные теги
    AND быстрые фильтры
    AND ручные условия по полям
    AND условия **Expression
```

Это не пять независимых поисков. Это один запрос текущей вкладки. Поэтому можно сначала найти
объекты по слову, затем сузить результат быстрыми фильтрами и в конце добавить точное условие в
расширенном поиске.

> Названия полей, статусы, процессы и остальные значения приходят с TACTIC-сервера. Примеры ниже
> показывают конструкцию запроса; используйте поля и значения своего проекта.

## Верхняя строка

| Элемент | Что делает |
| --- | --- |
| **Обновить текущие результаты** | Повторяет запрос текущей вкладки и получает актуальные данные с сервера. |
| **Строка поиска** | Ищет по имени или названию, ключевым словам и описанию — только по тем полям, которые существуют у текущего Search Type. |
| **Крестик в строке** | Очищает введённый текст. Чтобы выполнить очищенный запрос, нажмите `Enter`. |
| **Шелф скриптов** | Показывает или скрывает скриптовый шелф. Его подробности находятся в отдельном топике справки. |
| **Теги** | Открывает каталог тегов. Число на кнопке показывает количество выбранных тегов. |
| **Быстрые фильтры** | Открывает компактные фильтры текущей вкладки. Число на кнопке показывает количество выбранных значений. |
| **Справка** | Открывает этот топик. |
| **Панели рабочего пространства** | Открывает меню панелей текущего рабочего пространства. |

### Текстовый поиск и подсказки

1. Начните печатать. Подсказки появляются с небольшой задержкой.
2. Стрелки `↑` и `↓` перемещают выделение по подсказкам.
3. `Enter` на подсказке выполняет точный поиск по её имени или названию.
4. `Enter` без выбранной подсказки выполняет широкий поиск по доступным полям.
5. Средняя кнопка мыши на подсказке открывает её в новой вкладке поиска.
6. `Esc` закрывает список подсказок, не очищая уже введённый текст.

Широкий поиск слова `chair` превращается примерно в такую начальную группу:

```text
WHERE name        Contains  chair
OR    keywords    Contains  chair
OR    description Contains  chair
```

Если вместо `name` Search Type использует `title`, поиск возьмёт `title`. Отсутствующие поля в
запрос не добавляются.

Повторный поиск из верхней строки заменяет только эту начальную текстовую группу. Условия,
добавленные после неё, сохраняются. Очистка строки также убирает только текстовую часть запроса.

## Вкладки поиска и действия с результатами

| Кнопка или действие | Что делает |
| --- | --- |
| **Добавить вкладку поиска** | Создаёт новую независимую вкладку и переводит фокус в строку поиска. |
| **Фильтры поиска и пресеты** | Открывает меню расширенного поиска, фильтра процессов и сохранённых поисков. |
| **Клик по вкладке** | Активирует вкладку. |
| **Перетаскивание вкладки** | Меняет порядок вкладок. |
| **Крестик вкладки** | Закрывает вкладку, если она допускает закрытие. |
| **Средняя кнопка по вкладке** | Быстро закрывает вкладку, если она допускает закрытие. |
| **Все вкладки поиска** | Появляется при нехватке ширины, показывает полный список вкладок и позволяет активировать или закрыть нужную. |
| **Сортировка элементов** | Сортирует по имени A–Z, имени Z–A, времени обновления от новых к старым или от старых к новым. |
| **Группировка элементов** | Отключает группировку либо группирует по статусу SObject, пайплайну или доступному статусу задач выбранного процесса. |
| **Изменить вид результатов поиска** | Переключает непрерывное дерево, карточки, таблицу, компактные строки, версии справа или версии снизу. |
| **Действия с результатами** | В узком окне собирает сортировку, группировку и выбор вида в одно меню. |
| **История закрытых вкладок** | Восстанавливает недавно закрытую вкладку или очищает историю. Число на кнопке — количество доступных вкладок. |

### Меню «Фильтры поиска и пресеты»

| Пункт | Что делает |
| --- | --- |
| **Расширенный поиск** | Открывает редактор всех условий текущей вкладки. |
| **Фильтр процессов** | Настраивает, какие процессы и дочерние ветки показывать в дереве результатов. |
| **Сохранённый поиск** | Сразу загружает выбранный серверный пресет в текущую вкладку и выполняет его. |
| **Обновить сохранённые поиски** | Повторно получает список пресетов с TACTIC-сервера. |

В окне **Фильтр процессов** флажки управляют видимостью веток, **Сохранить** применяет изменения,
**Сохранить и закрыть** применяет и закрывает окно, а **Отмена** закрывает без сохранения.

## Теги

Кнопка **Теги** показывает каталог всего текущего Search Type. Каталог кэшируется по проекту и
Search Type и не сужается уже выполненным поиском.

| Кнопка или элемент | Что делает |
| --- | --- |
| **Плашка тега** | Добавляет тег в запрос; повторный клик снимает его. Несколько выбранных тегов объединяются через `OR`, а вся группа тегов присоединяется к предыдущим условиям через `AND`. |
| **Очистить теги** | Снимает все выбранные теги. |
| **Обновить теги** | Обходит кэш и заново получает каталог с сервера. |
| **Поиск тегов** | Фильтрует только список плашек в открытом окне; сам запрос результатов не меняет. |
| **Очистить поиск** | Очищает локальный поиск по каталогу тегов. |

Например, теги `vehicle` и `red` добавляют к существующему запросу группу вида:

```text
AND keywords Contains vehicle
OR  keywords Contains red
```

## Быстрые фильтры

Быстрые фильтры — это компактный интерфейс над обычными условиями расширенного поиска. Прямые
поля Search Type становятся условиями `Is` или `In`. Фильтры задач собираются в одно TEL-условие,
чтобы исполнитель, процесс и статус относились к одной и той же задаче.

| Кнопка или элемент | Что делает |
| --- | --- |
| **Значение фильтра** | Выбирает значение; повторный клик снимает его. Несколько значений одного прямого поля выполняются как `In`. |
| **Все** | Снимает выбор в данной группе. |
| **Мои задачи** | Ограничивает результат объектами с задачей, назначенной текущему TACTIC-пользователю. |
| **Выбрать пользователей / Пользователи** | Открывает выбор исполнителей для фильтра связанных задач. |
| **Применить общие настройки по умолчанию к этой вкладке** | Отбрасывает личную настройку этой вкладки и возвращает опубликованный общий вариант. Кнопка видна только после персонализации. |
| **Очистить быстрые фильтры** | Снимает все выбранные быстрые фильтры текущей вкладки. |
| **Редактировать** | Открывает редактор состава, порядка и стандартного выбора быстрых фильтров. |

### Редактор быстрых фильтров

| Кнопка или элемент | Что делает |
| --- | --- |
| **Крестик у выбранного значения** | Убирает одно значение из стандартного выбора. |
| **Копировать выбор из текущей вкладки** | Переносит текущие выбранные фильтры в редактируемый стандарт. |
| **Очистить выбранные фильтры** | Очищает весь редактируемый стандарт. |
| **Показывать скрытые фильтры** | Показывает группы, которые текущему пользователю разрешено вернуть. |
| **Флажок группы** | Показывает или скрывает группу целиком. |
| **Стрелки вверх и вниз** | Меняют порядок групп. |
| **Плашка значения** | Добавляет значение в стандарт; повторный клик убирает его. |
| **Сохранить** | Сохраняет состав и выбор локально для этой вкладки поиска. |
| **Сохранить как дефолты на сервере** | Доступно супервайзеру и публикует настройку для пользователей этой вкладки сайдбара. |
| **Отмена** | Закрывает редактор без сохранения текущих правок. |

Скрытые супервайзером группы не появляются у обычного пользователя. Каталог прямых полей включает
текстовые и числовые поля, в которых найдено не более 64 различных непустых значений. Даже поле с
одним значением остаётся доступным. Обновление каталога обходит кэш и не теряет несохранённые
правки редактора.

## Расширенный поиск

Откройте **Фильтры поиска и пресеты → Расширенный поиск**. Здесь запрос показан как список карточек.

### Кнопки верхней панели

| Кнопка | Что делает |
| --- | --- |
| **Стрелка у «Фильтры поиска»** | Сворачивает или раскрывает список условий. |
| **Применить фильтры** | Собирает активные карточки, возвращается к началу выдачи и выполняет запрос. |
| **Добавить фильтр** | Добавляет новую карточку условия. |
| **Сбросить фильтры** | Удаляет все условия и оставляет одну пустую стартовую карточку. |

### Элементы карточки условия

| Элемент | Что делает |
| --- | --- |
| **Флажок слева** | Временно включает или выключает ручное условие без его удаления. |
| **WHERE** | Помечает первое активное условие. Оно не переключается. |
| **AND / OR** | Соединяет текущую карточку с предыдущими условиями. Клик переключает `AND` и `OR`. |
| **Поле** | Выбирает колонку текущего Search Type или специальное поле `**Expression`. |
| **Отношение** | Выбирает сравнение, допустимое для типа поля. |
| **Значение** | Принимает значение фильтра. Для обычного поля показывает серверные подсказки; `Enter` сразу применяет весь запрос. |
| **Плюс первой карточки** | Добавляет ещё одно условие. |
| **Крестик карточки** | Удаляет условие. |
| **Редактировать как пользовательский фильтр** | Отвязывает карточку, созданную быстрыми фильтрами, и делает её обычной редактируемой карточкой. |
| **Удалить быстрый фильтр** | Удаляет сгенерированную карточку и соответствующий быстрый фильтр. |
| **Имя вкладки поиска** | Переименовывает только текущую вкладку, не меняя сам запрос. |

Карточка без поля, выключенная карточка и карточка без значения не отправляются на сервер. Исключение
— отношения вроде **Is empty**, которым значение не требуется.

### Отношения по типу поля

| Тип | Основные отношения |
| --- | --- |
| Текст | Is, Is not, Contains, Does not contain, Starts with, Ends with, In, Not in, Is empty, Is not empty, Is distinct. |
| Число и валюта | Equal, Greater than, Less than, In, Not in, Is empty, Is not empty, Is distinct. |
| Дата и время | Newer than, Older than, On, Is empty, Is not empty. |
| Пользователь | Is, Is not, Contains, Does not contain, Starts with, Ends with, Is empty, Is not empty. |
| Timecode | Before, After, Equal, Is empty. |
| `**Expression` | Have, Do not have, Match (slow), Do not match (slow). |

## Многослойный поиск: практические схемы

### Слово плюс точные поля

Сначала введите `chair` в верхней строке. Затем откройте расширенный поиск и добавьте условия:

```text
WHERE name        Contains chair
OR    keywords    Contains chair
OR    description Contains chair
AND   status      Is       Ready
AND   priority    Greater than 2
```

Так текст остаётся широким, а последние слои сужают результат по структурированным данным.

### Несколько допустимых значений

Для одного поля удобнее отношение **In**:

```text
WHERE status In Ready|In Progress|Review
```

Вертикальная черта разделяет значения списка. Тот же запрос можно собрать несколькими карточками
`status Is ...`, переключая соединитель на `OR`.

### Текст, быстрый фильтр и связанная задача

1. Найдите `dragon` в верхней строке.
2. В быстрых фильтрах выберите нужный прямой статус объекта.
3. Там же включите **Мои задачи** и нужный процесс.
4. Откройте расширенный поиск: текстовые условия и сгенерированные быстрые фильтры будут видны в
   одном списке.
5. При необходимости нажмите **Редактировать как пользовательский фильтр**, чтобы вручную изменить
   сгенерированное условие.

Условия интерфейса образуют плоскую цепочку: плашка `AND` или `OR` у карточки связывает её с
предыдущей частью запроса. Визуальных скобок и вложенных групп сейчас нет. Для сложной логики со
скобками используйте одно условие `**Expression` либо разнесите варианты по отдельным вкладкам и
сохранённым пресетам.

## `**Expression` и TEL

`**Expression` принимает серверное выражение TACTIC Expression Language (TEL). Это не Python и не
SQL.

### Have и Do not have

**Have** сначала вычисляет выражение, которое должно вернуть связанные SObject, а затем оставляет
объекты текущего Search Type, имеющие с ними связь. **Do not have** исключает такие объекты.

Объекты с задачей текущего пользователя:

```text
@SOBJECT(sthpw/task['assigned', '$LOGIN'])
```

Объекты с задачей заданного процесса и статуса:

```text
@SOBJECT(sthpw/task['process', 'animation']['status', 'In Progress'])
```

Выберите `**Expression → Have`, вставьте выражение и нажмите **Применить фильтры**. `$LOGIN`
подставляется TACTIC-сервером. Второй пример использует демонстрационные значения — замените их
реальными процессом и статусом проекта.

### Match (slow) и Do not match (slow)

**Match (slow)** вычисляет выражение отдельно для каждого объекта текущего Search Type и оставляет
объект, только если результат строго равен `True`. **Do not match (slow)** инвертирует выбор.

Например:

```text
@GET(.priority) == 3
```

```text
@GET(.status) == 'Approved'
```

Точка в `.priority` и `.status` означает поле проверяемого текущего объекта. Этот режим действительно
медленный: сервер сначала получает все объекты Search Type, затем вычисляет выражение для каждого.
Для связей с задачами, снапшотами и другими SObject предпочитайте **Have / Do not have**.

Если TEL некорректен, сервер вернёт ошибку запроса. Исправьте выражение; интерфейс не пытается
угадывать или переписывать его.

## Сохранённые поиски

Сохранённый поиск хранится на TACTIC-сервере и переносит весь набор карточек, включая `AND`, `OR` и
`**Expression`.

| Кнопка или пункт | Что делает |
| --- | --- |
| **Выбрать сохранённый поиск** | Загружает его карточки в редактор. В самом окне расширенного поиска после выбора нажмите **Применить фильтры**. |
| **Обновить выбранный пресет** | Перезаписывает выбранный пресет текущими карточками. |
| **Сохранить как новый пресет** | Просит имя и создаёт новый серверный пресет. |
| **Действия с сохранённым поиском** | Открывает дополнительные операции ниже. |
| **Переименовать пресет** | Меняет имя выбранного пресета. |
| **Дублировать пресет** | Создаёт копию под новым именем. |
| **Копировать ссылку сохранённого поиска** | Копирует ссылку, открывающую этот серверный поиск. |
| **Удалить пресет** | После подтверждения удаляет пресет с сервера. |
| **Обновить сохранённые поиски** | Заново получает список с сервера. |
| **Сохранить / Отмена в диалоге имени** | Подтверждает или отменяет создание, переименование либо дублирование. |

Выбор пресета из компактного меню над результатами применяется сразу. Выбор в верхней панели окна
расширенного поиска только подставляет карточки, чтобы их можно было проверить и поправить до
нажатия **Применить фильтры**.

## Нижняя панель результатов

| Кнопка или элемент | Что делает |
| --- | --- |
| **Диапазон результатов** | Показывает текущий диапазон и общее количество; в узком окне сокращается до общего количества. |
| **Предыдущая страница** | Переходит на предыдущую страницу в режиме страниц. |
| **Номера страниц** | Переходят непосредственно на выбранную страницу. В компактном режиме вместо них показывается `текущая / всего`. |
| **Следующая страница** | Переходит на следующую страницу в режиме страниц. |
| **Элементов на странице** | Выбирает 20, 25, 50 или 100 элементов. Доступно в развёрнутом режиме страниц. |
| **Страницы / Непрерывный** | Переключает обычную пагинацию и догрузку при приближении к концу списка. |
| **Синхронизировать текущий Search Type** | Открывает Repository Sync для текущего Search Type. |
| **Создать** | Открывает создание SObject текущего Search Type. |

В непрерывном режиме перетаскивание полосы прокрутки перемещает только по уже загруженным объектам.
Новая порция запрашивается при приближении к концу. Догрузка сохраняет текущую позицию и раскрытые
элементы и прекращается после конца выдачи.

## Что запоминается

Каждая вкладка хранит отдельно:

- карточки запроса, быстрые фильтры и выбранные теги;
- имя вкладки, сортировку, группировку и вид результатов;
- режим загрузки, размер страницы и уже загруженные страницы;
- компоновку доков и разделителей;
