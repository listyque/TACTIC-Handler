# Внешний агент

Откройте проект и страницу, выделите объекты, затем выберите **Дополнительные
действия → Внешний агент**. Откроется обычное модальное окно ТХ. В нём видны
захваченные проект, страница навигации, тип объектов, табличное представление и
ключи выделения. Проверьте контекст и опишите нужный результат. Сейчас нужны
права администратора и подключённый внешний процесс для того же пользователя
Тактика и проекта.

**Разрешить запрошенные изменения конфигурации** позволяет агенту использовать
штатное сохранение конфигурации и неактивных черновиков скриптов. Без отметки
доступны изучение и предпросмотр. Отправьте обращение и следите за ходом работы
и ответом в этом же окне. Результаты — обычные страницы, проекты и конфигурации
Тактика; обновите соответствующий список или кеш, чтобы увидеть их.

Закрытие окна оставляет задачу работать. При повторном открытии она сохранится;
список также содержит прежние обращения. **Новое обращение** захватывает текущие
страницу и выделение. Обращения независимы: передавайте нужные детали прежнего
ответа в продолжении. Смена проекта или выделения после отправки не меняет цель
уже отправленной задачи. Смена учётной записи очищает локальный контекст окна.

Отмена останавливает очередь или внешний процесс агента. Уже сохранённые
штатными командами операции остаются. После потери связи обращение станет
прерванным и автоматически не повторится. Проверьте изменения перед новой
попыткой. Если агент не подключён, отправка отключена: оператору нужно
восстановить подключение.

Агент работает через готовые API Тактика. Он может подготовить хуки чекина и
кнопки шелва и, если подключена проверочная среда, прогнать их на изолированных
данных Linux. Проверьте исходник, привязку и отчёты в **Редактор скриптов →
Черновики агента**, затем отдельно активируйте. Передача контекста не даёт
агенту живого управления ТХ или разрешения запускать сгенерированный Python на
Windows. Хуки чекина ТХ остаются локальным поведением клиента и не проверяют
загрузки браузера/API. Программы Windows и плагины студии требуют отдельной
ручной приёмки в обычном клиенте.
