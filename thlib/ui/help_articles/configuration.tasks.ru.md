# Настройка задач

> Здесь задаются начальный вид рабочего пространства задач и стандартные колонки Task Browser. Если
> для проекта или рабочего пространства уже сохранено состояние, оно имеет приоритет.

## Стандартный вид задач

| Параметр | Варианты и действие |
| --- | --- |
| **Начальная область задач** | Первой открывается **Быстрые задачи** или подробный **Task Browser**. |
| **Представление быстрых задач** | Показываются редактируемые **Карточки** процессов или **Компактный список**. |
| **Начальный вид** | При отсутствии сохранённого состояния открывается **Таблица** или **Гант**. |
| **Начальная сортировка** | До ручной сортировки упорядочивает по дедлайну, последнему изменению, процессу, исполнителю, статусу, родительскому объекту, приоритету, вехе или руководителю. |
| **Начальная группировка** | Группирует по процессу, статусу, исполнителю, родительскому объекту, проекту или Search Type либо использует режим **Без групп**. |
| **Разворачивать инспектор задач** | Открывает Task Inspector развёрнутым, если сохранённого состояния дока ещё нет. |

## Колонки таблицы задач

Каждая строка управляет одной колонкой. Галка показывает или скрывает её; обязательные колонки,
например **Объект**, скрыть нельзя. Числовое поле задаёт ширину от 40 до 480 независимых от DPI
пикселей. Две кнопки со стрелками двигают колонку влево или вправо в порядке отображения.

Геометрия доков и окон восстанавливается отдельно для каждого рабочего пространства. Область
задач, фильтры, свёрнутые группы, позиция календаря и выбранная задача возобновляются для каждого
проекта. Отмеченные задачи и несохранённые правки никогда не восстанавливаются.
