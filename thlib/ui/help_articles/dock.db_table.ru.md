# Док «Редактор базы данных»

> Редактор базы данных применяет контролируемые изменения полей к точному выделению sObject одного
> Search Type. Это массовый редактор, а не консоль сырой базы данных.

## Выделение и область

Док следует за выделением Поиска и хранит его отпечаток. Одну операцию могут разделять только
совместимые объекты активного Search Type. В заголовке показаны число объектов и изменённых полей,
поэтому смена выделения видна до применения.

## Редактирование полей

Выберите серверное поле, проверьте текущее значение и введите замену через подходящий редактор.
**Применить ко всем выбранным** подготавливает значение для всех объектов; иначе меняйте строки отдельно.

Колонки, типы, обязательность и каталоги приходят из TACTIC. Имена Search Types, статусы и проектные
подписи не выводятся догадкой и не переводятся редактором.

## Сохранение и отмена

- Изменённые ячейки помечены до успешного **Сохранить изменения**.
- Перед массовой записью проверьте число изменений и идентичности объектов.
- Отмена возвращает загруженные серверные значения без записи.
- Частичная или полная ошибка называет объект и сохраняет нерешённые правки видимыми.

## Безопасная последовательность

1. Сначала соберите и проверьте результат Поиска.
2. Выделите только нужные объекты.
3. Подтвердите Search Type и число объектов в редакторе.
4. Подготавливайте по одному полю и проверяйте изменённые ячейки.
5. Сохраните и обновите Поиск для проверки серверного результата.

## Ограничения и права

- Поля только для чтения, идентичности и неподдерживаемые поля не редактируются.
- Серверная проверка и права остаются окончательными.
- Редактор не создаёт побочно отсутствующие задачи или связанные объекты.
- Потеря выделения не перенаправляет подготовленный пакет на новый набор объектов.
