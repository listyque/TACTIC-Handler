# Keyboard shortcuts

> Keyboard commands follow the focused editor or view. Menus and dialogs also support standard Windows
> navigation.

## Main controls

Enter sends a message or note; Ctrl+Enter inserts a new line. In menus and combo boxes, Up and Down
move between choices, Enter or Space activates the focused choice, and Escape closes the popup.

Activating the same menu or combo box again also closes it. Snapshot previews use Left and Right.

Gantt editing supports undo and redo.

## Usage notes

- A shortcut is active only when its related window or editor has focus.

## Shortcuts

| Key | Action |
| --- | --- |
| Enter | Send a message or note |
| Ctrl+Enter | Insert a new line in a message or note |
| Esc | Close the active transient menu, search, or editor |
| Left / Right | Move between snapshot preview files |
| Ctrl+Z / Ctrl+Y | Undo or redo Task Gantt edits |
| Shift+click | Extend selection where the current list supports ranges |
