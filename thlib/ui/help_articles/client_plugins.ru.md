# Клиентские плагины

Войдите на сервер, выберите проект и откройте **Конфигурация → Клиентские плагины**.
Эти инструменты работают в ТХ. Их выпуски хранятся и публикуются на обычном
легаси-сервере TACTIC; установка ТС для этого не нужна.

Нажмите **Обновить**, затем на плагин для запуска. **Включён** управляет будущими
запусками для этого клиента и пары сервер/проект. Отключение не останавливает
работающую очередь. В списке показана доступная версия и версия открытого плагина.
Перед запуском ТХ перечитывает версию и групповые права. Открытый плагин сохраняет
свой код; закройте его и запустите снова, чтобы получить обновление. Во время
работы очереди сохраняйте текущую сессию и проект.

Администратор может собирать и обновлять пакет на этой же странице:

1. Укажите новый номер версии из трёх чисел, например **1.0.2**.
2. Нажмите **Собрать ZIP…**, выберите папку исходников с `plugin.json`, затем
   папку результата. Компилятор и отдельный Python не требуются.
3. Нажмите **Опубликовать ZIP…**, выберите архив и подтвердите текущий проект.
   Клиенты получат выпуск автоматически при следующем запуске плагина.
4. Для отката опубликуйте ранее собранный ZIP. Старые файлы выпусков сохраняются.

Исходники батча находятся в `plugins/batch_render` рабочего репозитория ТХ.
Альтернативный запуск сборки — **BUILD_BATCH_PLUGIN.bat**, для него нужен Python 3.
Тело диспетчера сохранено из проверенного экспорта ВМ. Запуск наследует существующие
групповые ограничения `stream/batch/dispatcher_runner`. Старые легаси-кнопки и
скрипты продолжают работать по прежним путям.

Пакет содержит исполняемый Python для рабочего компьютера. Публикуйте доверенный
код, не включайте секреты, настройки и билеты. Штатный веб-путь легаси может быть
публичным: групповые ограничения запуска не скрывают исходники и не являются
песочницей. Ошибка загрузки, контрольной суммы или совместимости блокирует запуск
нового кода. Настоящий рендер Maya/Redshift требует отдельной проверки.
