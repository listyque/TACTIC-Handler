# Клиентские плагины

Для запуска **батч-рендера** нажмите кнопку с иконкой кино рядом с выбором проекта в главном окне. В меню пользователя также доступны включённые инструменты, разрешённые вашим группам. Открывать конфигурацию для каждого запуска не нужно; ошибки запуска показываются уведомлением. Отключённые, запрещённые и недоступные плагины не предлагают запуск.

Войдите на сервер, выберите проект и откройте **Конфигурация → Клиентские плагины**.
Эти инструменты работают в ТХ. Их выпуски хранятся и публикуются на обычном
легаси-сервере TACTIC; установка ТС для этого не нужна.

Нажмите **Обновить**, чтобы получить список. Клик по строке только выделяет
плагин. Отдельная кнопка **Запустить** открывает инструмент; если он уже работает,
кнопка называется **Показать окно**. Кнопка кино и действия в меню пользователя
остаются командами прямого запуска. **Включено** делает плагин доступным для этого
клиента и пары сервер/проект, но само по себе не запускает его. Отключение не
останавливает работающую очередь. В списке показана доступная версия и версия открытого плагина.
Перед запуском ТХ перечитывает версию и групповые права. Открытый плагин сохраняет
свой код; закройте его и запустите снова, чтобы получить обновление. Во время
работы очереди сохраняйте текущую сессию и проект.

Администратор может собирать и обновлять пакет на этой же странице:

1. Нажмите **Собрать пакет плагина…**. Эта команда администратора создаёт пакет
   из исходников; для запуска или загрузки готового плагина она не нужна.
2. В отдельном диалоге укажите новую версию плагина из трёх чисел, например
   **1.2.1**. Поле изначально пустое. Отмена ничего не собирает и не меняет.
3. Нажмите **Собрать ZIP**, выберите папку исходников с `plugin.json`, затем
   папку результата. Компилятор и отдельный Python не требуются.
4. Нажмите **Опубликовать ZIP…**, выберите архив и подтвердите текущий проект.
   Клиенты получат выпуск автоматически при следующем запуске плагина.
5. Для отката опубликуйте ранее собранный ZIP. Старые файлы выпусков сохраняются.

Исходники батча находятся в `plugins/batch_render` рабочего репозитория ТХ.
Альтернативный запуск сборки — **BUILD_BATCH_PLUGIN.bat**, для него нужен Python 3.
Модульный плагин содержит очередь рендера и собственную веб-панель. Запуск наследует существующие
групповые ограничения `stream/batch/dispatcher_runner`. Старые легаси-кнопки и
скрипты продолжают работать по прежним путям.

Пакет содержит исполняемый Python для рабочего компьютера. Публикуйте доверенный
код, не включайте секреты, настройки и билеты. Штатный веб-путь легаси может быть
публичным: групповые ограничения запуска не скрывают исходники и не являются
песочницей. Ошибка загрузки, контрольной суммы или совместимости блокирует запуск
нового кода. Настоящий рендер Maya/Redshift требует отдельной проверки.

Опция **Автоматически запускать …** задаётся отдельно для
каждого плагина. После входа и выбора проекта открываются только отмеченные,
включённые и доступные вашим группам плагины. Галка не распространяется на все
установленные или включённые плагины. Настройка действует для текущего сервера и
проекта. Батч восстанавливает очередь на паузе; рендер запускает кнопка
**Запустить очередь**.

Код установленного батча находится в **plugins/batch_render** внутри папки
профиля клиента. Подпапок протокола, сервера, проекта и версии больше нет.
Повторное открытие проверяет права и обновляет эту же папку. Открытый плагин
сохраняет свой код; сначала закройте его для обновления или другого сервера/проекта.
Настройки лежат отдельно: **settings/batch_render.json**, состояние окна —
**settings/batch_render_window.json**, очередь — **settings/batch_render_queue.json**.
Разные аккаунты, серверы и проекты разделяются записями внутри JSON, поэтому
чужая очередь не восстанавливается. Версия остаётся в метаданных пакета, а не
в имени локальной папки. Старые каталоги исходников не являются конфигом батча.

Поиск и фильтры статусов работают сразу, без повторной загрузки списка с сервера.
Пустые и нестандартные статусы также доступны в фильтре. Кнопка **Веб-панель** открывает
веб-панель батча; для другого компьютера скопируйте защищённую LAN-ссылку.
В настройках рендера можно выбрать порт и защиту доступа. Занятый порт отображается
как ошибка. Закрытие плагина останавливает его веб-панель. Сводка нативного окна
использует Tactic Frame; веб-панель остаётся отдельным пультом этой же очереди.

Добавление эпизода только получает его шоты: статус задачи на сервере не меняется,
Maya не запускается. Для новых эпизодов нажмите **Запустить очередь**, даже если
предыдущая очередь уже работала. **Запустить только это** и **Тестовый рендер** —
явные команды запуска. Сохранённая очередь открывается на паузе.

В новом профиле включены все настроенные статусы рендера, кроме **Проверен** и
**Без статуса рендера**. Сохранённый выбор фильтров остаётся прежним. Shift+клик
выделяет диапазон шотов, Ctrl+клик добавляет или убирает шот. Ctrl+A выделяет
все шоты текущего эпизода. Стрелки перемещают фокус, Shift+стрелки расширяют
выделение. Пробел или флажок выделенного шота включает/исключает всю выделенную
группу. Флажок эпизода меняет все доступные шоты и показывает смешанное состояние
при частичном включении. Завершённые, активные и ожидающие подтверждения записи
шоты защищены. За грип можно перемещать и исключённые шоты. Обычное выделение
сохраняет прокрутку обоих списков.

Нативное окно и веб-панель используют язык интерфейса ТХ, одинаковые высоты
карточек, превью, отступы и цвета темы. Названия и статусы проекта сохраняются.
Выделение обновляет только изменённые строки, обновления вывода рендера
объединяются без потери сообщений лога. Чтобы получить опубликованное обновление,
закройте уже открытый плагин и запустите его снова.
