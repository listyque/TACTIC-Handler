# Настройка сцены Maya

## Интеграция Maya

Нажмите **Найти Maya**: в списке появятся установленные версии Maya для Windows,
запущенные процессы, существующие профили и установленные подключения Stream.
Выберите строку и нажмите **Интегрировать в Maya**. Требуется Maya с Python 3
(2022 и новее). Поиск учитывает каталоги установки Autodesk, пути запущенных
процессов, профили текущего пользователя и переменную `MAYA_APP_DIR`.

Установка добавляет отдельный шелф **TACTIC_Stream** с кнопкой запуска ТХ и
изолированный модуль автозапуска коннектора. Ваши startup-скрипты, старые шелфы
и кастомные скрипты сохраняются. Maya может запросить разрешение на выполнение
нового startup-скрипта согласно своим настройкам безопасности.
Кнопка запуска использует собственную оранжевую монограмму TH. При запуске оформление
обновляется только у принадлежащих интеграции кнопок. Для обновления существующего
подключения после замены сборки снова нажмите **Интегрировать в Maya** и перезапустите Maya.

Изменения применяются при следующем запуске Maya. Коннектор ожидает именно эту
сборку ТХ, автоматически не запускает её и не открывает окно. Кнопка шелфа
показывает подключённый ТХ либо запускает соседний portable EXE. При обновлении
ТХ в той же папке переустановка интеграции не нужна; после переноса папки
выполните интеграцию заново. Подключения разных сборок не смешиваются. Если
в Maya уже загружен SDK другого ТХ, сохраните работу и перезапустите Maya.

**Удалить интеграцию** удаляет только принадлежащие ей файлы. Изменённые файлы
и чужой шелф с таким же именем сохраняются с сообщением об ошибке. Перед удалением
закройте Maya, чтобы она не сохранила удалённый шелф обратно. Установку можно
подготовить при открытой Maya; она применяется при следующем запуске. Уже открытая
Maya не перезапускается, код в её процесс не внедряется. Эти кнопки сразу меняют интеграцию;
кнопки применения и отмены настроек страницы на них не влияют.

Поиск и запуск portable EXE доступны в Windows-клиенте ТХ; аналога в браузерном
TACTIC Stream нет.

Вся интеграция принадлежит DCC-плагину Maya. Включить или отключить его можно в
**Настройки → DCC-плагины**; выбор применяется после перезапуска ТХ. Если подключения
Maya больше не нужны, удалите их до отключения плагина: само отключение не удаляет
внешние файлы и пользовательские данные.
После удаления кеш Python и пустые папки не считаются установленной интеграцией.
Повторная установка автоматически восстанавливает подключение при таких остатках
и сохранённом собственном шелфе. Посторонние файлы и чужие шелфы защищены.

> Здесь задаются значения для подключённой Maya при открытии, сохранении и подготовке сцены к
> самостоятельному Check-in в TACTIC Handler.

## Окружение сцены Maya

| Параметр | Что делает |
| --- | --- |
| **Текущий рабочий каталог** | Корень проекта, который выбранная Maya сообщает при подключении. Значение обновляется при повторном чтении сцены и очищается после отключения клиента. **Рабочий каталог не выбран** означает, что Maya ещё не сообщила его. |
| **Формат сохранения Maya** | Стандартный Maya ASCII или Maya Binary, предлагаемый при подготовке сцены к Check-in. Сам по себе не конвертирует уже открытую сцену. |
| **Создавать каталоги Maya** | Подготавливает стандартную структуру Maya Project, когда она нужна сценарию Check-in. |
| **Создавать плейбласт** | Подготавливает изображение плейбласта для снапшота, если исходный сценарий поддерживает плейбласт. |

## Поведение окон

**Возвращать фокус после открытия сцены** выводит Maya на передний план после открытия, импорта или
референса. **Возвращать фокус после сохранения сцены** делает то же после сохранения или подготовки
к Check-in. Отключите соответствующий переключатель, если после действия нужно остаться в TACTIC
Handler.

Эти параметры относятся только к действиям Maya DCC. После получения результата подготовки
репозиторием и Check-in по-прежнему занимается самостоятельное приложение TACTIC Handler.
