# Component showcase

Open **Administration -> Component showcase** to explore Tactic Frame's existing
controls in the current theme. The catalogue contains 29 families in six groups.
All 29 families have live examples and source descriptions.

Search by name, token or native/Vue component name. Filter by group or select a
family. Use the state selector for normal, disabled, read-only, error, long-text,
loading, empty and selected
examples. Not every state changes every kind of control. **Reset** restores the
local sample. **Code example** shows the shared Frame description where available.

Examples include typography, headers, colors, icons, buttons, toggles, text and
numeric inputs, choices, dates, users, pickers, tabs, badges, lists and charts.
Badge examples distinguish status chips from counters; list examples include
count rows and two-line rows. Native/Vue names show where the family is implemented.

Search has local suggestions. Menus include checks, a submenu and disabled
actions; right-click and the visible trigger use the same menu. Confirmation
supports Apply, Cancel and Escape. Feedback includes progress and Retry. The
table has 100 local editable rows; split panes can be resized or collapsed.
Previews have crop/contain and selection. Choose or drop files to display their
names, edit source in the source editor, and select/move graph nodes. Input
examples count actual activations and accept input-method text. The task fragment
switches surfaces and saves its draft only inside the example.

Examples use local sample data. They do not save settings, modify the current
project or run server commands. Code is read-only and can be copied through the
existing source-editor controls. The window can be closed without a save prompt.
