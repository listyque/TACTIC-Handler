# Component showcase

Open **Administration -> Component showcase** to explore Tactic Frame's existing
controls in the current theme. The catalogue contains 29 families in six groups.
Sixteen families have live examples; other entries identify existing components
whose standalone examples have not been added yet.

Search by name, token or native/Vue component name. Filter by group or select a
family. Use the state selector for normal, disabled, read-only, error and long-text
examples. Not every state changes every kind of control. **Reset** restores the
local sample. **Code example** shows the shared Frame description where available.

The first live set includes typography, headers, colors, icons, buttons, toggles,
text and numeric inputs, choices, dates, users, pickers, tabs, badges, lists and charts.
Badge examples distinguish status chips from counters; list examples include
count rows and two-line rows. Native/Vue names show where the family is implemented.

Examples use local sample data. They do not save settings, modify the current
project or run server commands. Code is read-only and can be copied through the
existing source-editor controls. The window can be closed without a save prompt.
