# Настройка кэша

> Здесь отдельно настраиваются сохранённая структура вкладок поиска и кэш серверных записей. Кнопки
> обновления всегда запрашивают актуальные данные у TACTIC независимо от этих переключателей.

## Кэш рабочего пространства

| Параметр или действие | Что делает |
| --- | --- |
| **Кэшировать вкладки процессов** | Восстанавливает сохранённую структуру вкладок процессов вместо перестроения всех вкладок из проектных данных при запуске. |
| **Очистить кэш вкладок** | Удаляет только кэш структуры Search Tab. При следующей загрузке вкладки перестраиваются из актуальных проектных данных. |

## Кэш серверных данных

Включённый переключатель разрешает локально восстанавливать неизменившиеся записи категории.
Отключение заставляет последующие загрузки снова запросить данные, но не выключает саму функцию.

| Категория | Что кэшируется |
| --- | --- |
| **Проекты и справочные данные** | Проекты, Search Type, пайплайны, процессы, статусы, пользователи, группы и теги. |
| **Результаты поиска и sObject** | Упорядоченные страницы поиска и неизменившиеся поля объектов Search Tab. |
| **Снапшоты и файлы** | Метаданные снапшотов и файлов. Реальные файлы репозитория остаются в ведении Repository Sync. |
| **Дочерние объекты и связи** | Раскрытые дочерние ветви и состав связанных объектов. |
| **Задачи** | Области Task Manager, страницы и метаданные задач. |
| **Заметки** | История заметок объектов и процессов вместе с метаданными вложений. |
| **Сообщения** | Ограниченный набор недавних диалогов и метаданные вложений. |
| **Лента активности** | Недавние страницы активности и полные счётчики дней календаря. |
| **Рабочие часы** | Результаты запросов табеля и отчётов для ранее открытых диапазонов. |

## Обслуживание кэша

**Очистить все кэшированные серверные данные** удаляет перечисленные категории, но сохраняет
структуру Search Tab, черновики и расположение окон. Данные повторно загружаются по мере надобности.
Перед очисткой увеличивается поколение кэша, поэтому старый фоновый запрос не сможет вернуть
устаревшие записи. В окне подтверждения **Отмена** ничего не меняет, а **Очистить кэш** выполняет
операцию.
