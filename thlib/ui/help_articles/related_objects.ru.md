# Связанные объекты

При подключении к Stream Handler загружает список связей с правами вашей роли.
Окно различает отсутствие настроенной связи и режим чтения. Для создания
записи также нужен доступ к редактору Handler.

Откройте кнопку связей на строке или карточке объекта. Меню показывает связанные типы и пункт **Связанные объекты**. Выберите тип сразу либо откройте окно и выберите **Тип связанных объектов**. Запрос остаётся привязан к исходному объекту: фильтрация и страницы не превращают его в поиск по всему проекту.

У окна стандартный заголовок, тень, изменение размера и разворачивание с восстановлением. Закрытие сохраняет основной поиск. Смена проекта или подключения отменяет прежний контекст.

**Создать связанный объект** открывает существующую форму создания с исходным объектом. Действия над строками используют штатные операции и серверные проверки прав. **Связывание существующих объектов** остаётся отдельным редактором связей через таблицу экземпляров; проверки несохранённых изменений и неизвестного результата записи сохраняются.
