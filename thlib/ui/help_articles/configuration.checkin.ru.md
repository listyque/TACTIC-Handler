# Настройка параметров Check-in

> Здесь задаются вид результатов, параметры снапшотов, передача файлов, Repository Sync, завершение
> Drop Plate и автоматическое распознавание файлов. Это значения по умолчанию; конкретная операция
> может разрешать явное переопределение в Commit Queue.

## Результаты поиска

| Параметр | Что делает |
| --- | --- |
| **Доставка превью** | Загружает превью через HTTP-адрес TACTIC вместо обязательного прямого доступа к пути репозитория. |
| **Встроенные процессы** | Показывает встроенные процессы TACTIC вместе с проектными процессами в результатах. |
| **Лимит результатов** | Запрашивает от 20 до 5000 sObject на страницу. Большая страница реже переключается, но требует больше времени и памяти на один запрос. |
| **Режим загрузки** | **Страницы** используют явные кнопки назад/вперёд; **Непрерывно** запрашивает следующую страницу при достижении конца списка. |
| **Стандартный вид результатов** | Открывает **Непрерывный** список или **Карточки**, если у Search Tab нет сохранённого вида. |

## Взаимодействие с элементами

**Двойной клик для сохранения** скачивает или сохраняет выбранный снапшот настроенным методом
Check-out. **Shift + двойной клик для открытия** запускает выбранный файл в связанном приложении.
Отключите жест, если двойной клик должен только выбирать элемент.

## Версии и описания

| Параметр | Что делает |
| --- | --- |
| **Отделять версии** | Выносит версии снапшота в отдельную область, не смешивая их с основным содержимым элемента. |
| **Положение версий** | Размещает отдельную область **Справа** или **Снизу**; доступно только при разделённых версиях. |
| **Длина описания** | При включении обрезает описание до 20–50000 символов. Отключение показывает полный текст. |

## Стандартный вид Snapshot Browser

| Параметр | Варианты и действие |
| --- | --- |
| **Показывать все снапшоты** | Добавляет снапшоты всех процессов, а не только выбранного. |
| **Показывать больше метаданных** | Изначально раскрывает раздел дополнительных метаданных. |
| **Начальное содержимое** | Показывает **Превью и файлы**, **Только превью** или **Только файлы**. |
| **Начальная ориентация** | Располагает превью и файлы рядом (**Горизонтально**) или сверху вниз (**Вертикально**). |

## Передача файлов

**Метод Check-in** выбирает контракт TACTIC: **Preallocate** заранее подготавливает финальный путь в
репозитории; **In-Place** регистрирует файл, уже лежащий по пути репозитория; **Copy** копирует
исходник в репозиторий; **Move** перемещает его; **Upload** передаёт через серверный адрес. Copy и
In-Place сохраняют исходник, а Move намеренно переносит его.

**Метод Check-out** использует **Local** для прямого доступа к пути репозитория или **HTTP** для
скачивания через TACTIC. HTTP нужен, когда компьютер не видит пути репозитория напрямую.

## Создание снапшота

| Параметр | Что делает |
| --- | --- |
| **Обновлять versionless-снапшот** | Обновляет `latest`/versionless после успешной нумерованной версии. |
| **Создавать превью** | Создаёт поддерживаемые миниатюры и превью во время подготовки. |
| **Очищать завершённые элементы Commit Queue** | Автоматически удаляет успешные операции. Ошибки и отменённые строки остаются. |
| **Подтверждать сохранение** | Спрашивает подтверждение перед сохранением подготовленной операции Check-in. |
| **Подтверждать сохранение ревизии** | Отдельно спрашивает перед сохранением ревизии вместо новой версии. |
| **Разрядность последовательности** | Включает фиксированные 1–9 цифр в создаваемом номере кадра. Число доступно только при включённом переключателе. |

## Синхронизация репозитория

| Параметр | Что делает |
| --- | --- |
| **Проверять файлы по MD5** | Сравнивает контрольные суммы для поиска изменившихся локальных файлов. Надёжнее проверки метаданных, но требует дополнительных CPU и дисковых операций. |
| **Очищать завершённые загрузки** | Удаляет успешные строки Repository Sync после каждого пакета скачивания. |
| **Режим обнаружения** | **Полный охват** сначала находит всё запрошенное дерево; **Частичный охват** чередует обнаружение и передачу блоками. |
| **Размер блока частичного охвата** | Использует от 1 до 250 записей репозитория на блок и доступен только в частичном режиме. |

## Завершение Drop Plate

| Параметр | Что делает |
| --- | --- |
| **Общий Drop Plate для вкладок** | Использует один совместимый набор файлов между Search Tab вместо отдельного набора каждой вкладки. |
| **Снимать отметку с отправленных файлов** | Оставляет успешные файлы в Drop Plate, но снимает с них галки. |
| **Удалять отправленные файлы** | Удаляет успешные файлы из Drop Plate. Неуспешные остаются для проверки. |

## Сопоставление и именование файлов

| Параметр или действие | Что делает |
| --- | --- |
| **Группировать выбранные файлы** | Подготавливает один многофайловый снапшот вместо отдельного снапшота для каждого файла. |
| **Сохранять исходное имя** | Оставляет имена источников вместо активного шаблона именования. |
| **Включать подпапки** | Рекурсивно сканирует вложенные каталоги, добавленные в Drop Plate. |
| **Разрешать одиночный UDIM или UV-тайл** | Считает один подходящий тайл валидным набором, не требуя нескольких. |
| **Разрешать однокадровую последовательность** | Считает один нумерованный файл последовательностью, если разрядность подходит под правила. |
| **Минимальная разрядность кадра** | Автоматически распознаёт последовательность, только если номер содержит не меньше заданных 1–9 цифр. |
| **Шаблоны сопоставления — Открыть** | Открывает шаблоны, связывающие добавленные файлы с контекстами Check-in. |
