# Настройки и создание проектов

> Настройки проектов и быстрое окно выбора показывают активные, архивные, шаблонные и встроенные
> проекты TACTIC. Карточки отображают категорию, тип, жизненный цикл, код, описание, серверный статус
> и квадратное web-превью из репозитория. Фильтры архивных, шаблонных и встроенных проектов выключены
> по умолчанию и общие для обоих представлений; контролы перестраиваются, не перекрывая список.

## Основные элементы

Выберите и активируйте существующий проект. Команда редактирования открывает нативное модальное окно
для изменения имени, категории, типа, описания, признака шаблона, состояния архива и превью.

Встроенные проекты TACTIC видимы, но доступны только для чтения. Новое превью подготавливается через
обычную очередь Commit Queue и не загружается из UI-потока.

«Выбрать изображение» подготавливает замену превью. «Отменить выбор изображения» возвращает прежнее
превью до сохранения.

## Как пользоваться

- Создание нового проекта открывает нативный многошаговый мастер.
- В нём предусмотрены шаги для имени и кода, шаблона, превью, категорий и проверки.
- Создание проекта пока остаётся заготовкой UI: кнопка создания отключена, а редактирование
  существующих проектов уже работает.
