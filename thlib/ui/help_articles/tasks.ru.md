# Задачи и планирование

> Инструменты задач предоставляют редактирование задач объекта и проектные представления: таблицу,
> диаграмму Ганта, календарь, табель и отчёты.

## Основные элементы

Используйте область задач, фильтры команд, быстрые фильтры, колонки, сортировку, группировку,
массовое выделение, редакторы статуса и исполнителя, даты, прогресс, заметки и удаление. Значок
задач на sObject или процессе открывает менеджер задач в области «Выбранное».

Выбор строки задачи обновляет инспектор для этой задачи, не меняя сохранённое развёрнутое или
свёрнутое состояние инспектора. Если у одного процесса несколько задач, меню бейджа показывает
контекст, исполнителя и статус каждой задачи; строка процесса открывает список задач из уже
загруженных данных.

## Как пользоваться

- Только область «Выбранное» следует за выделением sObject; области проекта, Search Type,
  пользователя и команды не меняются, а компактные редакторы задач продолжают следовать за выбранным
  результатом.
- Значки заметок используют нативные счётчики TACTIC по процессам.
- «Редактировать sObject» открывает редактор на основе серверной схемы и всегда загружает явно
  запрошенный объект, даже если окно уже открыто.
- Удаление открывает общий редактор зависимостей, где перед удалением можно проверить заданные
  TACTIC зависимости и галки по умолчанию.
- При удалении задачи заметки того же родительского sObject и процесса показываются отдельной
  отмеченной группой зависимостей; снимите галку, чтобы сохранить их.
- Ссылки на задачи из ленты активности, сведений об объекте и профилей пользователей принимают оба
  нативных формата search key TACTIC.
- Обновление области «Выбранное» без sObject сохраняет обычное пустое состояние и не отправляет
  запрос на сервер.
- Область «Выбранное» следует за активной вкладкой поиска и выделенными в ней объектами, включая
  множественное выделение.
- Действие «Все» для типа поиска использует тип этой вкладки, даже если список результатов пуст.
- Скрытые представления задач учитывают актуальный выбор при повторном открытии; несохранённые
  правки задач сохраняются.
- Группы задач по Search Type показывают настроенное название, сохраняя серверный код как стабильный
  идентификатор.
- Фильтрация, группировка и сортировка задач выполняются на сервере до разбивки на страницы.
- «Загрузить ещё» получает следующую страницу результатов; несохранённые изменения задач остаются
  доступны при смене фильтра.
- Редакторы при наведении создаются только при необходимости.
- После нажатия редактор статуса или пользователя остаётся активным, пока открывается его меню,
  поэтому указатель можно сразу переместить в меню.
- Щёлкните правой кнопкой по заголовку колонки для сортировки, группировки, видимости и настройки
  колонок.
- Черновое расписание Ганта остаётся в разделе «Задачи без расписания» до успешного сохранения.
- Пустой менеджер задач сохраняет футер и показывает по центру подсказку создания со стрелкой к
  кнопке +.
- При изменении ширины дока стрелка остаётся привязана к кнопке создания.
- Таблица создаётся асинхронно только при наличии задач в активной области; диаграмма Ганта
  создаётся при первом запросе и сохраняется для плавного переключения.
- Первая загруженная таблица менеджера задач и пакет быстрых задач раскладываются до показа, поэтому
  строки задач не появляются каскадом при запуске.
- Списки выбора пользователей объединяют разрешённые для задачи варианты с общими данными профилей,
  согласованно отображают группы и результаты поиска и сохраняют исходный вариант при фильтрации.
- Список пользователей подготавливается уже при нажатии на селектор, поэтому его отдельное
  всплывающее окно не открывается с пустым первым кадром.
- Хедер менеджера задач удерживает переключатель представления, меню дополнительных действий и
  обновление у правого края, а второстепенные действия на узкой ширине переносит в это меню.
- После перезапуска менеджер задач отдельно для каждого проекта восстанавливает последний охват,
  фильтры, свёрнутые группы, положение календаря и выбранную задачу.
- Отмеченные строки и несохранённые правки намеренно очищаются.
- Поиск задач остаётся видимым в узкой компоновке.
- Компактная кнопка области остаётся рядом с созданием задачи и не занимает гибкое пространство
  строки поиска; на минимальной ширине выбор области доступен из меню дополнительных действий.
