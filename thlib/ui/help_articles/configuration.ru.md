# Конфигурация

Заголовок страницы и её действия находятся в общей шапке.
Сворачивание и разворачивание выполняются нативными средствами окна.
При закрытии проверяются несохранённые изменения.

Длинные страницы прокручиваются колесом мыши или тачпадом над содержимым. Общая полоса прокрутки видна, когда страница не помещается по высоте.

> В окне конфигурации редактируется по одной странице параметров. Кнопка справки рядом с заголовком
> текущей страницы открывает точное описание каждого параметра именно этой страницы.

## Навигация по страницам

Слева выбираются **Сервер**, **Репозитории**, **Проекты**, **Параметры Check-in**, **Общие**,
**Внешний вид**, **Кэш**, **Задачи** и **Сцена Maya**. Точка возле страницы означает, что её черновик
отличается от сохранённой конфигурации.

## Общие кнопки

«Сбросить» и «Применить» для текущей страницы, а также «Сохранить» и «Закрыть» для всего окна
находятся в верхней строке рядом с заголовком. В узком окне они показаны иконками с подсказками.

| Кнопка | Что делает |
| --- | --- |
| **Справка** | Открывает статью для показанной сейчас страницы, а не общую статью о настройках. |
| **Сбросить** | Возвращает сохранённые значения текущей страницы. Доступна только при несохранённых изменениях. |
| **Применить** | Применяет текущую страницу, не закрывая окно конфигурации. |
| **Сохранить** | Сохраняет изменения конфигурации, не закрывая окно. После сохранения всех изменений кнопка становится неактивной. |
| **Закрыть** | Запрашивает закрытие окна. При наличии черновиков можно сохранить их, отбросить или вернуться к редактированию. |

Настройки одной страницы не перезаписывают другую. У длинных страниц остаётся видимая полоса
прокрутки, а серверные названия проектов, процессов, репозиториев и Search Type отображаются ровно
так, как их прислал TACTIC.

## Где хранятся значения

Пользовательские параметры сохраняются через общий API конфигурации TACTIC Handler. На странице
**Общие** показан активный корень конфигурации для диагностики. Геометрия окон и временное рабочее
состояние сохраняются отдельно от пользовательских параметров.

## Общая компоновка

Конфигурация использует общую навигацию Tactic Frame и одинаковые строки настроек в Handler и Stream. Длинные страницы оставляют место видимой полосе прокрутки; на телефоне вместо боковой панели появляется выбор раздела. У страниц независимые черновики. Сохранение нативных пресетов сохраняет правки других страниц. Локальные/DCC/трей/GPU-настройки принадлежат Handler, XML сервера, web-пути и браузерные предпочтения — Stream. В Handler нет встроенного браузера.

В узком редакторе репозиториев действия сброса и синхронизации представлены иконками с полными подсказками; подпись сохранения остаётся видимой. Кнопки сохранения проекта и установки шаблона сохраняют полные подписи на английском и русском языках.

На странице «Проекты» каталог и действия проекта разделены подложками с рамками. Фильтры находятся в шапке каталога, счётчик — в его нижней строке, прокручивается сам список. В узком окне блок действий располагается над каталогом.

В разделе «ИИ-провайдеры» редактор подключений открывается прямо в конфигурации. Выберите или создайте подключение, измените настройки и используйте его кнопки «Сохранить» и «Проверить подключение». Переключение разделов сохраняет черновик; скрытый редактор прекращает опрос подключения. Смена учётной записи очищает черновик. Из чата агента тот же редактор по-прежнему можно открыть отдельным окном.

Форма нового ИИ-подключения сохраняется, пока вы выбираете провайдера, даже до ввода имени. Фоновые проверки и переходы между страницами конфигурации её не сбрасывают. Сохранение профиля провайдера не запускает внешнего исполнителя: для ожидающей проверки нужен исполнитель под той же учётной записью Тактика, а для чата — ещё и подключённый к текущему проекту.

Нажмите **Подключить агента** в чате или **Конфигурация → ИИ-провайдеры**: исполнитель запустится на сервере Тактика для вашей учётной записи и текущего проекта. **Отключить агента** останавливает его; текущая задача прерывается, уже применённые изменения сохраняются. Закрытие окна не отключает исполнителя. Исполнитель, запущенный вне UI, останавливается там, где был запущен. Вход в Codex или ключи другого провайдера должны быть настроены на серверной машине; браузер не запускает процесс на своём компьютере.
