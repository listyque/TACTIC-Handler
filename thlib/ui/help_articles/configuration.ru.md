# Конфигурация

> В окне конфигурации редактируется по одной странице параметров. Кнопка справки рядом с заголовком
> текущей страницы открывает точное описание каждого параметра именно этой страницы.

## Навигация по страницам

Слева выбираются **Сервер**, **Репозитории**, **Проекты**, **Параметры Check-in**, **Общие**,
**Внешний вид**, **Кэш**, **Задачи** и **Сцена Maya**. Точка возле страницы означает, что её черновик
отличается от сохранённой конфигурации.

## Общие кнопки

| Кнопка | Что делает |
| --- | --- |
| **Справка** | Открывает статью для показанной сейчас страницы, а не общую статью о настройках. |
| **Сбросить** | Возвращает сохранённые значения текущей страницы. Доступна только при несохранённых изменениях. |
| **Применить** | Применяет текущую страницу, не закрывая окно конфигурации. |
| **Сохранить** | Сохраняет изменения конфигурации и закрывает окно. |
| **Отмена** | Запрашивает закрытие окна. При наличии черновиков можно сохранить их, отбросить или вернуться к редактированию. |

Настройки одной страницы не перезаписывают другую. У длинных страниц остаётся видимая полоса
прокрутки, а серверные названия проектов, процессов, репозиториев и Search Type отображаются ровно
так, как их прислал TACTIC.

## Где хранятся значения

Пользовательские параметры сохраняются через общий API конфигурации TACTIC Handler. На странице
**Общие** показан активный корень конфигурации для диагностики. Геометрия окон и временное рабочее
состояние сохраняются отдельно от пользовательских параметров.
