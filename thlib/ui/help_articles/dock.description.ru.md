# Док «Описание»

> Описание показывает и редактирует текст текущего sObject, процесса или снапшота и умеет закрепить
> один текст как описание следующего чекина.

## Текущая цель

В заголовке указаны точные объект и область показанного описания. Выбор в Поиске, процесс и снапшот
могут менять цель. Режим редактирования создаёт локальный черновик; смена выделения не записывает его
молча в другой объект.

## Элементы

| Элемент | Поведение |
| --- | --- |
| **Редактировать** | Открывает текущий текст как черновик. |
| **Сохранить** | Записывает черновик в его текущую цель. |
| **Отмена** | Удаляет только этот черновик и возвращает сохранённый текст. |
| **Закрепить** | Использует это описание для чекина при дальнейшей смене выделения. |
| **Открепить** | Снова выбирает описание по текущему контексту. |

Док различает состояния **Редактирование**, **Не сохранено**, **Сохранение** и **Для чекина**.
Закреплённый текст не копируется в описание другого объекта, а только выбирается для Очереди отправки.

## Обычная последовательность

1. Выберите нужные объект, процесс или снапшот.
2. Проверьте заголовок цели до редактирования.
3. Измените и сохраните хранимое описание.
4. Закрепите его, только если оно должно перейти в следующий подготовленный чекин.
5. После чекина открепите, чтобы снова следовать за текущим выделением.

## Состояния и ошибки

- **Нет описания** означает, что у цели пока нет сохранённого текста.
- **Нет цели** означает, что рабочее пространство не опубликовало подходящее выделение.
- Ошибка сохранения оставляет черновик для исправления и повтора.
- Закрытие или скрытие дока не сохраняет редактируемый текст автоматически.
