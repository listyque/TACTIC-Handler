# Каталог компонентов

Откройте **Администрирование -> Каталог компонентов**, чтобы посмотреть компоненты
Tactic Frame в текущей теме. В каталоге 29 семейств в шести группах. Для 16 семейств
есть живые примеры; остальные карточки показывают существующие компоненты,
отдельные примеры которых пока не добавлены.

Ищите по названию, токену или имени компонента QML/Vue. Можно выбрать группу и
семейство. Переключатель состояния показывает обычный, отключённый вариант,
ошибку, режим только чтения или длинный текст. Не каждое состояние меняет каждый
тип компонента. **Сброс** восстанавливает локальный пример. **Пример кода** открывает
описание через общий API Frame, если оно доступно для выбранного примера.

Первый набор включает типографику, заголовки, цвета, иконки, кнопки, переключатели,
текстовые и числовые поля, выбор значений, даты, пользователей, пикеры, вкладки,
бейджи, списки и диаграммы. У бейджей отдельно показаны статусы и счётчики;
у списков — строки со счётчиками и двухстрочные строки. Внизу указаны реализации
семейства в QML и Vue.

Примеры работают на локальных данных: настройки и записи проекта не сохраняются,
команды серверу не отправляются. Код доступен только для чтения; копирование
использует обычные кнопки редактора. Закрытие окна не требует сохранения.
