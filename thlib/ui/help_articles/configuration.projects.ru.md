# Настройка проектов

> На странице выбирается проект рабочего пространства и открываются создание и редактирование
> проектов. Выбор общий с переключателем проектов в главном окне.

## Доступные проекты

| Элемент | Что делает |
| --- | --- |
| Фильтр **Архивные** | Добавляет в список проекты со статусом retired. Сам фильтр их не активирует. |
| Фильтр **Шаблоны** | Добавляет в список шаблоны проектов. |
| Фильтр **Встроенные** | Добавляет системные проекты TACTIC. Их можно активировать, но нельзя редактировать здесь. |
| Карточка проекта | Выбирает проект для просмотра. Двойной клик активирует его. Карточка показывает серверные название, код, категорию, тип, статус и описание, если они заданы. |

## Проект рабочего пространства

Метка **Текущий** показывает проект, который сейчас использует рабочее пространство. **Активировать
выбранный проект** переключает всё рабочее пространство: Search Type, навигация, задачи и проектные
данные загружаются для нового контекста. **Редактировать выбранный проект** открывает редактор и
недоступна для встроенных проектов. **Создать новый проект** открывает пустой редактор проекта.

Обычный выбор карточки ничего не переключает — проект меняется только после активации или двойного
клика.
