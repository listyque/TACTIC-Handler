# Начало работы

> Подключитесь к серверу TACTIC, выберите проект, затем выберите Search Type или сохранённый поиск в
> панели навигации.

## Основные элементы

В верхней панели находятся выбор проекта, состояние подключения, выбранный DCC-клиент, очередь,
активность, тема, Конфигурация и действия профиля. Ниже расположено рабочее пространство с
перемещаемыми доками и вкладками поиска.

## Как пользоваться

- Если сервер ещё не настроен, сначала откройте Конфигурацию.
- Search Types, процессы, статусы, группы, контексты и пайплайны проекта отображаются в точности
  так, как их передаёт TACTIC.
- TACTIC Handler работает в одном экземпляре.
- Повторный запуск восстанавливает уже открытое главное окно, в том числе когда оно скрыто в
  системном трее.
- В Windows оба способа запуска используют значок Handler на панели задач.
- После обновления полностью перезапустите Handler.

## Первое подключение

1. Откройте **Конфигурация → Сервер**.
2. Выберите или создайте пресет и проверьте адрес, portal site и прокси.
3. Кнопка **Проверить** тестирует видимый черновик без сохранения и запроса пароля.
4. Кнопка **Создать тикет** выполняет вход и сохраняет страницу сервера.
5. Настройте пригодный дефолтный репозиторий, когда Handler предложит настройку.

Доступность сервера и авторизация — разные состояния: доступный endpoint может потребовать новый
тикет, а сохранённый тикет может истечь при работающем сервере.

## Выбор проекта

Откройте селектор проекта, включайте фильтры retired, шаблонов и встроенных проектов только при
необходимости, затем активируйте проект. Активация перезагружает Search Types боковой панели,
сохранённые поиски, задачи и метаданные. Простое выделение карточки проект не переключает.

## Поиск и проверка работы

1. Откройте Search Type или сохранённый поиск из панели навигации.
2. Сузьте результат текстом, тегами, Быстрыми фильтрами или Расширенным поиском.
3. Выберите sObject, чтобы передать его Браузеру снапшотов, Задачам, Описанию и Инспектору.
4. Затем выберите процесс, задачу, контекст, снапшот или файл.
5. Используйте меню элемента для разрешённых состоянием действий: правки, связи, дубликата, удаления, чекина или DCC.

## Необязательное подключение Maya

Запустите установленную кнопку Handler из Maya. В верхнем селекторе появятся приложение, сцена и PID.
До открытия, импорта, референса, сохранения, DCC-скрипта или триггера выберите нужный процесс. За
синхронизацию файлов и чекин TACTIC всё равно отвечает Handler.

## Если запуск не завершился

- Откройте **Ошибку приложения** и скопируйте полный traceback.
- В **Журнале отладки** выберите группу запуска или соединения и скопируйте путь сессии.
- Отдельно проверьте адрес, VPN/прокси, тикет и репозиторий.
- Для Maya проверьте `maya.status()` и вывод Script Editor Maya.
