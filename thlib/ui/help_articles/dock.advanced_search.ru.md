# Док «Расширенный поиск»

> Расширенный поиск строит явные правила полей, связей и выражений для активной вкладки Поиска.
> Он дополняет текст, теги и Быстрые фильтры, а не заменяет их.

## Область действия

При открытии из результатов док редактирует Search Type и пресеты этой вкладки. При открытии из
Редактора боковой панели он работает с полной библиотекой сохранённых поисков выбранного Search Type.
Перед применением или сохранением всегда проверяйте показанный Search Type.

## Структура фильтра

Каждая включённая строка содержит поле или выражение, оператор и значение. Строки соединяются через
**AND** или **OR** и могут образовывать вложенные группы. Выключите строку, чтобы проверить запрос,
не удаляя правило.

| Элемент | Назначение |
| --- | --- |
| Поле | Выбирает колонку активного Search Type. |
| Оператор | Сравнение, диапазон, вхождение, текстовая или пустая проверка, доступная типу поля. |
| Значение | Литерал, пункт каталога, дата или выражение. |
| AND / OR | Требует обе ветки или допускает любую из них. |
| Группа | Задаёт порядок вычисления многослойного запроса. |
| Применить | Отправляет фильтр в активную вкладку Поиска. |
| Сбросить | Возвращает начальные правила редактора без изменения серверных данных. |

## Быстрые и собственные правила

Быстрый фильтр может добавлять несколько правил. Отсоедините его, если правила нужно редактировать как
обычный собственный фильтр. После отсоединения изменения исходного Быстрого фильтра не переписывают копию.

Текст, теги, Быстрые фильтры и Расширенный поиск объединяются. Неожиданно пустой результат часто
означает, что корректное правило другого слоя всё ещё активно.

## Выражения и связи

Строки выражений предназначены для TEL и переходов по связям, которые нельзя описать прямым полем.
Подсказки зависят от Search Type и схемы проекта. Серверные идентификаторы полей, процессов и Search
Types вводите точно, не переводя их.

## Пресеты

Пресет хранит полный документ фильтра своей области. **Обновить выбранный пресет** заменяет его,
**Сохранить как новый пресет** оставляет старый. Ссылка сохранённого поиска открывает сохранённые
правила, а не копию текущих строк результата.

## Обычная последовательность

1. Проверьте активные Search Type и вкладку.
2. Сначала добавьте самые узкие правила прямых полей.
3. Используйте связи и выражения только там, где прямых полей недостаточно.
4. Явно сгруппируйте AND/OR и временно выключайте строки для проверки.
5. Примените запрос и проверьте число результатов.
6. Сохраняйте пресет после проверки всех слоёв поиска.

## Ошибки

- Некорректное значение или выражение остаётся в редакторе вместе с сообщением проверки.
- Удалённое из серверной конфигурации поле нужно заменить; UI не переосмысливает его имя.
- Пустой фильтр очищает только слой Расширенного поиска.
- Серверная ошибка сохраняет черновик для исправления или повтора.
