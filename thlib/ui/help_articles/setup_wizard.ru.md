# Мастер настройки Windows

Запустите **TACTIC-Handler-Setup-<версия>.exe** на новом или существующем рабочем
месте. Выберите пустую папку приложения или существующую установку ТХ. Установщик
содержит Python и Qt; отдельно устанавливать Python не нужно. При обновлении
сохраняются настройки, логи и локальные скрипты, а предыдущая папка остаётся рядом
для отката. Сначала закройте ТХ, включая значок в трее. Установщик предназначен
для Windows; у браузерного ТС такого локального мастера нет.

Для повторной настройки запустите **TH Setup.exe** из папки приложения или ярлык
**TACTIC Handler Setup**. Во время настройки ТХ должен оставаться закрытым.
Тонкая шкала под формой показывает все пять шагов. Длинные формы прокручиваются,
ошибки показываются на текущем шаге,
а перед применением каждый параметр отдельно виден на странице проверки.

1. Укажите корневой адрес сервера и войдите в свою учётную запись. Пароль не
   сохраняется. Логин всегда изначально пустой. В обычном установщике адрес сервера
   тоже пустой; командный установщик может содержать заданный администратором адрес. «Назад» сохраняет введённые поля и выбор проекта, репозитория, плагинов,
   версий Maya и полки для того же аккаунта и проекта. Пароль остаётся только в
   памяти до применения или выхода. В обычном профиле ТХ хранится билет сессии.
   Неверная пара логин/пароль, ошибки соединения, HTTP и сертификата, а также
   ошибка загрузки проектов показываются отдельно. Сервер не уточняет, какая
   часть пары логин/пароль неверна.
2. Выберите проект, алиас репозитория и локальную или сетевую папку. Для новой
   настройки по умолчанию используется **repo** внутри выбранной папки установки ТХ.
   Она создаётся при применении; уже настроенный путь остаётся выбранным.
   Другие папки должны существовать. При обновлении папка **repo** сохраняется.
   Это путь на данном компьютере. Серверные пути репозиториев не меняются.
3. Включите нужные плагины DCC. Для Maya с Python 3 (2022 и новее) доступны поиск
   и автоматическая установка. Выберите закрытые версии Maya и полку проекта.
   Вариант «Только кнопка запуска» не устанавливает кнопки кастомных скриптов.
   Другие перечисленные DCC-адаптеры можно включить, их установка в DCC пока ручная.
4. Проверьте параметры и создание ярлыков ТХ и мастера на рабочем столе. Нажмите
   «Применить», затем «Готово». Перед использованием интеграции перезапустите Maya.

Мастер предлагает личные полки вошедшего пользователя и общие полки. В предпросмотре
нет отсутствующих скриптов, неподдерживаемых языков и скриптов, запрещённых группам
пользователя. Перед применением права перечитываются с сервера. Кнопки вызывают
существующие точки входа ТХ; тела скриптов не копируются и не переписываются.
После изменения групп или состава полки снова запустите мастер для её обновления
в Maya. При запуске кнопки ТХ повторно проверяет права: локальная полка не является
границей авторизации или песочницей для произвольного Python.

Мастер сохраняет те же параметры, что разделы «Конфигурация → Сервер», «Репозиторий»
и «Плагины DCC». При ошибке восстанавливаются затронутые настройки, ярлыки и файлы
управляемой интеграции. Чужие и изменённые файлы интеграции Maya сохраняются, мастер
сообщает о конфликте. Отмена до применения не сохраняет выбранные параметры.
Учётные записи, группы, права, схемы и серверные скрипты не меняются.

Чтобы собрать преднастроенный установщик для команды без компилятора и отдельного
Python, запустите **TH Setup Builder.exe** из папки приложения. Выберите базовый
установщик (или ранее созданный EXE), задайте общие параметры по умолчанию (адрес
сервера, код проекта, папку установки, имя папки репозитория, плагины DCC, полку
и ярлыки рабочего стола) и нажмите «Создать EXE». Логины, пароли и билеты сессии
в установщик никогда не сохраняются.
