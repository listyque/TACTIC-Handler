# Редактор боковой панели

> Редактор меняет проектную навигацию, хранящуюся в TACTIC. Обычный режим покрывает стандартную
> настройку, а XML редактирует выбранный серверный элемент напрямую. Сохраняйте
> осознанно: изменения затрагивают пользователей, которым виден элемент.

Открывайте его в разделе **Редактор боковой панели** окна администрирования. Селектор проекта
в админке определяет, чей сайдбар редактируется; вкладка поиска на этот выбор не влияет.

## Заголовок и режимы

| Элемент | Что делает |
| --- | --- |
| **TH / TACTIC** | Выбирает независимый сайдбар TACTIC Handler либо нативный веб-сайдбар TACTIC `project_view`. |
| **Обычный** | Показывает страницы «Элемент», «Доступ» и «Технические» для выбранного элемента. |
| **XML** | Показывает сырой XML выбранного элемента. Нужен только для серверного параметра, которого нет в обычном режиме. |
| **Справка** | Кнопка в заголовке админки открывает эту статью для редактора боковой панели. |
| **Перезагрузить боковую панель** | Повторно читает конфигурацию с сервера. Во время операции кнопка недоступна. |

При смене режима текущее текстовое поле обычного редактора сначала фиксирует значение. В режиме XML
**Применить XML** проверяет и применяет текст к выбранному элементу черновика; вся боковая панель
попадёт в TACTIC только после кнопки **Сохранить**.

## Элементы боковой панели

Дерево слева показывает будущую структуру навигации. Клик выбирает строку, стрелки раскрывают
разделы. Сайдбар TH хранится в самостоятельном представлении `tactic_handler` и больше не считается
подразделом нативного TACTIC `project_view`.

Для любого проекта без настроенного сайдбара навигация показывает загруженные Search Type проекта.
Этот автоматически составленный список не записывается в XML сайдбара. Сохранённый сайдбар Handler,
включая явно пустой, имеет приоритет; список не возвращает пункты, скрытые правилами доступа.
Стандартные ссылки веб-сайдбара без определений элементов не блокируют этот автоматический список.

При редактировании TH селектор групп показывает **Все группы** либо сайдбар глазами одной группы
логинов. Предпросмотр фильтрует по черновым галкам доступа, а скрытые из навигации элементы оставляет
приглушёнными в редакторе, чтобы их можно было выбрать и вернуть. Новый пункт,
созданный при выбранной группе, получает доступ для этой группы; вернитесь к **Всем группам**, чтобы
увидеть или изменить скрытые от неё пункты. Сам селектор ничего отдельно не сохраняет: единственным
источником групповой видимости остаются права каждого пункта.

| Кнопка добавления | Результат |
| --- | --- |
| **Добавить ссылку** | Создаёт элемент, открывающий поиск. |
| **Добавить раздел** | Создаёт группу для вложенных ссылок. |
| **Добавить разделитель** | Создаёт видимую черту; разделитель остаётся выбираемым и перемещаемым. |

Над настройками кнопки **Вверх**, **Вниз** и **Удалить** работают с выбранным элементом. Удаление
убирает только строку черновика, пока боковая панель не сохранена.

## Страница «Элемент»

| Параметр | Что делает |
| --- | --- |
| **Название** | Видимая подпись в боковой панели. Не меняет стабильное внутреннее имя. |
| **Иконка** | Открывает библиотеку иконок с поиском. |
| **Показывать в навигации** | Скрывает элемент в навигации, не удаляя настройки; в редакторе он остаётся приглушённым. |
| **Search Type** | Объекты проекта, которые открывает ссылка. Ссылка без Search Type остаётся приглушённой и не открывает поиск. |
| **Предустановленный поиск** | Сохранённый запрос стартового фильтра либо отсутствие пресета для полного списка. |
| **Стандартный вид элементов** | Начальное дерево, карточки, компактные строки или разделённые версии. |
| **Раскладка рабочего пространства** | Серверная расстановка доков, применяемая при открытии ссылки. При следующих входах может восстановиться сохранённое состояние вкладки. |
| **Скриптовый шелф** | Общий проектный шелф, показываемый при активности этой вкладки. |
| **Настроить поиск** | Открывает реальное рабочее пространство Search Type. Список пресетов включает только поиски, сохранённые в TACTIC Handler; обновление повторно загружает этот же список. Здесь также настраиваются быстрые фильтры, видимость процессов, сортировка, группировка и вид результатов. |

## Страница «Доступ»

В **Кому виден элемент** перечислены доступные группы логинов. Отметьте только те, которым нужен
элемент: эти же черновые значения сразу используются предпросмотром TH. **Управлять группами и
участниками** переключает админку на раздел «Группы»; изменение состава групп там не является правкой текущего
черновика. Пустой список означает, что сервер не отдал группы.

## Страница «Технические»

| Параметр | Значение |
| --- | --- |
| **Тип элемента** | Ссылка открывает поиск, раздел группирует дочерние элементы, разделитель делит список. |
| **Внутреннее имя** | Стабильный серверный идентификатор и владелец стандартных быстрых фильтров. Для визуального переименования меняйте «Название». |
| **Дочернее представление** | Представление `SideBarWdg`, содержащее дочерние элементы раздела. |
| **Имя иконки** | Сырой серверный идентификатор; для обычного выбора безопаснее страница «Элемент». |
| **Тип виджета** | Веб-виджет TACTIC для ссылки. Представление результатов Handler задаётся на странице «Элемент». |
| **Путь класса** | Зарегистрированный Python-класс этого виджета TACTIC. |
| **Представление** | Серверный view, который отрисовывает выбранный виджет TACTIC. |

## Сохранение и отмена

Назначенный сохранённый поиск задаёт первую вкладку пункта меню и не открывается
повторно отдельной вкладкой. Повторный выбор пункта сохраняет активную вкладку,
фильтры и черновик поиска. Другие сохранённые поиски остаются отдельными, даже
если их названия совпадают. Кнопка **+** создаёт дополнительный личный поиск.

Нижняя строка сообщает, есть ли правки. **Отбросить** возвращает все черновики к загруженному
серверному состоянию. **Сохранить** записывает их в TACTIC и обновляет проектную навигацию. Если
элемент управления недоступен, выберите совместимую строку или дождитесь завершения запроса.

Текст полей и XML учитываются как черновик ещё до применения. Переход между страницами, режимами или элементами сначала применяет текущий текст. Неверный XML остаётся в редакторе вместе с ошибкой; закрытие и смена проекта не теряют его. Удаление элемента, сохранение и сброс требуют подтверждения. Удаление меняет только черновик до записи на сервер.

В узком окне выберите элемент дерева, чтобы открыть его настройки; «Назад» возвращает к дереву, сохраняя правки. У дерева, списка прав групп и настроек свои полосы прокрутки. Неизвестный результат сохранения запрещает повторную запись до подтверждённой загрузки серверного состояния.
