# Док «Задачи»

> Задачи следуют за выбранным sObject и редактируют задачи его воркфлоу. Одна верхняя строка переключает
> компактные карточки, список и полный Менеджер задач, не перемещая основные элементы.

## Область и виды

Для выбранного sObject док загружает процессы настроенного воркфлоу и их задачи:

| Вид | Для чего удобен |
| --- | --- |
| Карточки | Быстрая смена статуса, исполнителя, дат и прогресса по процессам. |
| Список | Плотный обзор большого числа процессов. |
| Полный Менеджер задач | Серверные фильтры, таблица, Gantt, Календарь, массовое редактирование и подробности. |

Смена вида сохраняет цель и несохранённые правки. Таблица, Gantt и Календарь находятся в нижней строке
полного рабочего пространства.

## Строки процессов

Строка процесса умеет сбросить или сохранить правки, создать отсутствующую задачу, открыть заметки и
показать действия редактирования или удаления. Если у процесса несколько задач, сначала выберите точную.

Обычно доступны статус, исполнитель, даты начала и окончания, прогресс, приоритет и бид. Набор полей и
значений приходит из воркфлоу проекта. Каталоги статусов и пользователей загружаются по требованию.

## Сохранение

- **Сохранить** в строке записывает одну задачу.
- **Сохранить всё** записывает все изменённые строки текущей цели.
- **Отменить** восстанавливает серверные значения строки.
- **Отменить всё** убирает все несохранённые изменения дока.
- Быстрое создание использует дефолты процесса; полный Редактор задач показывает дополнительные поля.

Изменённые строки явно помечены. Смена выделения не коммитит их молча.

## Заметки и рабочие часы

Открытие Заметок заставляет Инспектор задач следовать точным родителю, процессу и задаче. Учёт времени
использует эту идентичность; у процесса без задачи сначала нужно создать задачу.

## Даты и загрузка

Поле даты показывает локализованную дату и добавляет время, только когда хватает места. Фокус открывает
точное редактируемое значение. В длинном списке сначала прокрутите и дождитесь остановки, затем используйте hover-действия.

## Ошибки и права

- Отсутствие процессов означает, что у объекта нет настроенного или доступного воркфлоу.
- При конфликте сохранения локальная правка остаётся видна для проверки или отмены.
- Удаление показывается только при подходящих правах и состоянии задачи.
- Недоступный пользователь, статус или поле — серверная конфигурация; UI не придумывает их сам.
