# Док «Поиск»

В раскрытой ветке связи или процесса нажмите небольшую лупу слева от её названия, чтобы найти дочерние записи. Крестик очищает фильтр; Enter/Escape закрывает поиск. Остальные ветки и сами записи не меняются.

> Поиск — основной браузер проекта. Каждая вкладка хранит свой Search Type, фильтры, вид результатов,
> раскрытые строки, выделение, режим страниц и позицию прокрутки.

## За чем следит док

Активный пункт боковой панели выбирает Search Type или сохранённый поиск. Выбранный результат
передаёт текущие sObject, процесс и снапшот остальным докам. Возврат на загруженную вкладку показывает
сохранённую поверхность, не запрашивая и не перестраивая каждую строку заново.

## Верхняя строка

Грип перемещения дока остаётся в левом верхнем углу, когда «Поиск» и «Снапшоты»
объединены в стек, поэтому переключение вкладки не перемещает область перетаскивания.
Даты в таблице отображаются в общем локализованном формате. Наведите указатель на дату, чтобы увидеть полную дату и время без микросекунд из базы данных.
Кнопка настройки колонок закреплена справа в заголовке; полосы прокрутки занимают отдельные отступы за пределами ячеек таблицы.
Заголовки таблицы оформлены так же компактно и в верхнем регистре, как в Диспетчере задач. При сужении таблицы необязательные колонки исчезают в настроенной очерёдности: номер 1 скрывается первым, а 0 оставляет колонку видимой. Кнопка **Автоподбор ширины колонок** растягивает оставшиеся колонки на доступную ширину; ширина и порядок скрытия меняются в настройках колонок.
Щёлкните заголовок таблицы правой кнопкой, чтобы отсортировать данные по возрастанию или убыванию, сгруппировать по этой колонке либо убрать группировку. Активная колонка выделяется цветом и значком; заголовки групп можно сворачивать и раскрывать.
Превью в таблице заполняет круг: края изображения обрезаются без искажения пропорций.

| Элемент | Назначение |
| --- | --- |
| Поле поиска | Ищет в текущей вкладке и показывает серверные подсказки. |
| Обновить текущие результаты | Повторяет текущий запрос, не заменяя фильтры. |
| Скриптовый шелф | Показывает личный или общий шелф для текущей вкладки. |
| Теги | Добавляет и очищает фильтры тегов; ввод фильтрует загруженный каталог. |
| Быстрые фильтры | Включает сохранённые условия для данного Search Type. |
| Панели рабочего пространства | Показывает, скрывает и восстанавливает доки проекта. |

При малой ширине поиск, обновление, Теги и Быстрые фильтры остаются доступны напрямую, а вторичные
действия переходят в дополнительное меню.

## Вкладки поиска

- **Добавить вкладку поиска** создаёт независимый контекст результатов.
- **Фильтры и пресеты поиска** (значок воронки) редактируют правила и пресеты активной вкладки.
- **Все вкладки поиска** находит открытую вкладку в длинном списке.
- Наведение на вкладку слева раскрывает её над рабочей областью, не меняя раскладку доков.
- Закрытие не активирует вкладку; историю закрытых вкладок можно восстановить.
- Шелф конкретной вкладки перекрывает общий шелф только для неё.

## Представление результатов

Нижняя строка и дополнительное меню содержат **Сортировку**, **Группировку**, **Вид результатов** и
**Действия с результатами**. В компактном меню сортировка, группировка и вид раскрывают подменю;
обновление остаётся рядом с поиском. Дерево, список и карточки используют один запрос и выделение;
смена вида не редактирует данные проекта. В подзаголовке sObject показываются описание, пользовательское
название пайплайна и настроенная категория; технический code пайплайна остаётся только запасным вариантом.
Название категории берётся из серверных values/labels поля, включая выражения.
Справочник загружается в фоне, кэшируется и перечитывается при обновлении результатов.
Для неизвестной категории отображается её код.
Двойной клик по тегам или многострочному описанию открывает широкую панель редактора.
Добавляйте теги через Enter или «Добавить», удаляйте по одному и применяйте кнопкой «Сохранить».
«Отмена» или Escape отменяют черновик; сам ввод текста ничего не сохраняет.
Редактор ячейки таблицы показывает полный список вариантов исходного поля, в том числе
когда колонка связана с другим полем через серверные настройки действия.
При временной ошибке сервера загрузка вариантов поля повторяется до трёх попыток;
если ошибка сохраняется, она отображается пользователю.
Таблица результатов оформлена как Диспетчер задач: скруглённая шапка, горизонтальные разделители без вертикальной сетки и высота строк по умолчанию 58. Круглые превью вписываются в строку; расширение их колонки само по себе не увеличивает высоту строки.
Записи заметок используют название и цвет процесса из активного пайплайна; число справа показывает количество заметок этого процесса.
В табличном виде режим **По размеру Preview** увеличивает строку вместе с колонкой Preview. Пресеты
«Компактно», «Комфортно» и «Крупно» задают точную высоту строки. Task Workflow разделяет статус и
исполнителя. Карточки сохраняют одинаковую ширину; если все карточки не помещаются, наведение на ячейку
Task Workflow показывает те же редактируемые карточки поверх таблицы. Индикатор задач по центру
открывает Диспетчер задач этого объекта. В высоких строках также показываются
локализованные даты начала и окончания задач; нажмите на строку дат, чтобы изменить оба значения.
Смена статуса, исполнителя или дат задачи создаёт локальный черновик для выделенных строк.
Над таблицей появляются кнопки сохранения и сброса со счётчиком изменённых задач.
Календари задач загружаются только по нажатию на даты, а не для каждой строки при открытии таблицы.
Схлопывание группы сохраняет несохранённые изменения задач. Если строка используется для другого объекта, открытый редактор задачи закрывается, а не переключает цель редактирования.
Сохранение применяет все подготовленные изменения, сброс отменяет их. При ошибке
неподтверждённые изменения остаются; смена выделения не сохраняет и не удаляет черновики.
Сохранение поля объекта обновляет только затронутые строки таблицы, сохраняя прокрутку и выделение.
При наведении на ячейку с неуместившимися задачами карточки раскрываются поверх той же строки в стороны, в пределах окна. Исходные карточки на время раскрытия скрываются, поэтому задачи не дублируются. При мультивыделении наведение на workflow выбранной строки раскрывает задачи всех видимых выбранных строк. Остальные ячейки не запускают раскрытие.
В карточном виде клик по карточке выделяет её, кнопки на ней выполняют свои действия, а клик по пустому месту сетки снимает выделение.
Название и описание объекта расположены под верхними кнопками карточки. Для задач и заметок выделена отдельная нижняя зона, в том числе при нулевых счётчиках.
Скругление карточек и превью сохраняется во время прокрутки.
Карточки связей постоянно показывают создание объекта и, для связей instance, привязку существующего.
У непустой связи есть кнопка «Открыть»; двойной клик по карточке открывает то же содержимое.

Дочерние строки иерархии загружаются при раскрытии. Ctrl и Shift расширяют выделение. Контекстное меню
всегда относится к строке под указателем; средняя кнопка открывает новую вкладку только для sObject.
Удаление доступно только для своего объекта, созданного менее часа назад. При множественном
выделении этому условию должен соответствовать каждый объект; перед удалением проверка повторяется.

## Страницы и синхронизация

| Элемент | Поведение |
| --- | --- |
| Предыдущая / следующая страница | Переходит по серверным страницам. |
| Номер страницы | Открывает известную страницу. |
| Размер страницы | Меняет число строк в запросе. |
| Страницы / Непрерывно | Переключает явные страницы и подгрузку при прокрутке. |
| Синхронизировать Search Type | Обновляет серверные метаданные и состояние этого Search Type. |

Непрерывный режим добавляет следующую страницу у конца списка. Это не означает, что уже загружены все
серверные строки: счётчики и массовые действия различают загруженные записи и весь запрос.

## Обычная последовательность

1. Откройте Search Type или сохранённый поиск из боковой панели.
2. Добавьте текст, теги, быстрые фильтры или правила Расширенного поиска.
3. Выберите группировку и вид, не меняя сам запрос.
4. Выделите результаты и используйте контекстные или дополнительные действия.
5. Проверьте снапшоты, задачи, описание и заметки в следующих доках.

## Пустые состояния и ошибки

- Индикатор загрузки относится к текущему поколению запроса; старый ответ не применяется к новой вкладке.
- Пустой список означает, что комбинация фильтров не вернула строк, а не отсутствие Search Type.
- Серверная ошибка сохраняет вкладку и фильтры, чтобы Обновить повторило тот же запрос.
- **Сбросить раскладку** восстанавливает геометрию доков, но не удаляет сохранённые поиски.

## Отсутствующий versionless

Если у коммита нет versionless-снапшота, поиск показывает его отсутствие без статуса файла Online/Offline. Доступность файла относится к существующему снапшоту: у существующего снапшота с недоступными файлами надпись «Файл недоступен» сохраняется.

Раскрытая таблица подстраивается под короткий список вместо пустой панели высотой 320 px. Длинные списки сохраняют ограниченную область с прокруткой; вложенные строки перестраиваются без повторной загрузки уже полученных данных. У блока один внешний отступ, а место под горизонтальную прокрутку резервируется при переполнении колонок. Для галочек и превью используются компактные ширины по умолчанию; заданные в настройках ширины сохраняются.

Вложенные таблицы используют доступную высоту рабочей области поиска. Короткий список занимает высоту строк; длинный прокручивается после заполнения доступного места. Изменение размера сохраняет выделение и загруженные данные. Явно заданные размеры панелей дашборда сохраняются.
