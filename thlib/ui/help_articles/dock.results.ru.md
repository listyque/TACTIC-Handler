# Док «Поиск»

> Поиск — основной браузер проекта. Каждая вкладка хранит свой Search Type, фильтры, вид результатов,
> раскрытые строки, выделение, режим страниц и позицию прокрутки.

## За чем следит док

Активный пункт боковой панели выбирает Search Type или сохранённый поиск. Выбранный результат
передаёт текущие sObject, процесс и снапшот остальным докам. Возврат на загруженную вкладку показывает
сохранённую поверхность, не запрашивая и не перестраивая каждую строку заново.

## Верхняя строка

| Элемент | Назначение |
| --- | --- |
| Поле поиска | Ищет в текущей вкладке и показывает серверные подсказки. |
| Обновить текущие результаты | Повторяет текущий запрос, не заменяя фильтры. |
| Скриптовый шелф | Показывает личный или общий шелф для текущей вкладки. |
| Теги | Добавляет и очищает фильтры тегов; ввод фильтрует загруженный каталог. |
| Быстрые фильтры | Включает сохранённые условия для данного Search Type. |
| Панели рабочего пространства | Показывает, скрывает и восстанавливает доки проекта. |

При малой ширине поиск, обновление, Теги и Быстрые фильтры остаются доступны напрямую, а вторичные
действия переходят в дополнительное меню.

## Вкладки поиска

- **Добавить вкладку поиска** создаёт независимый контекст результатов.
- **Фильтры и пресеты поиска** редактируют правила и пресеты активной вкладки.
- **Все вкладки поиска** находит открытую вкладку в длинном списке.
- Наведение на вкладку слева раскрывает её над рабочей областью, не меняя раскладку доков.
- Закрытие не активирует вкладку; историю закрытых вкладок можно восстановить.
- Шелф конкретной вкладки перекрывает общий шелф только для неё.

## Представление результатов

Нижняя строка и дополнительное меню содержат **Сортировку**, **Группировку**, **Вид результатов** и
**Действия с результатами**. Дерево, список и карточки используют один запрос и выделение; смена вида
не редактирует данные проекта.

Дочерние строки иерархии загружаются при раскрытии. Ctrl и Shift расширяют выделение. Контекстное меню
всегда относится к строке под указателем; средняя кнопка открывает новую вкладку только для sObject.

## Страницы и синхронизация

| Элемент | Поведение |
| --- | --- |
| Предыдущая / следующая страница | Переходит по серверным страницам. |
| Номер страницы | Открывает известную страницу. |
| Размер страницы | Меняет число строк в запросе. |
| Страницы / Непрерывно | Переключает явные страницы и подгрузку при прокрутке. |
| Синхронизировать Search Type | Обновляет серверные метаданные и состояние этого Search Type. |

Непрерывный режим добавляет следующую страницу у конца списка. Это не означает, что уже загружены все
серверные строки: счётчики и массовые действия различают загруженные записи и весь запрос.

## Обычная последовательность

1. Откройте Search Type или сохранённый поиск из боковой панели.
2. Добавьте текст, теги, быстрые фильтры или правила Расширенного поиска.
3. Выберите группировку и вид, не меняя сам запрос.
4. Выделите результаты и используйте контекстные или дополнительные действия.
5. Проверьте снапшоты, задачи, описание и заметки в следующих доках.

## Пустые состояния и ошибки

- Индикатор загрузки относится к текущему поколению запроса; старый ответ не применяется к новой вкладке.
- Пустой список означает, что комбинация фильтров не вернула строк, а не отсутствие Search Type.
- Серверная ошибка сохраняет вкладку и фильтры, чтобы Обновить повторило тот же запрос.
- **Сбросить раскладку** восстанавливает геометрию доков, но не удаляет сохранённые поиски.
