# Общие настройки

> Общие настройки управляют жизненным циклом приложения, уведомлениями, лимитами воркеров,
> категориями диагностических событий и показывают активный каталог конфигурации.

## Приложение и уведомления

| Параметр | Что делает |
| --- | --- |
| **Закрывать в системный трей** | Оставляет TACTIC Handler запущенным после нажатия кнопки закрытия главного окна. Отключите, если закрытие окна должно завершать процесс. |
| **Уведомления ленты активности** | Показывает уведомление справа снизу, когда другой пользователь создаёт событие активности. Применяется сразу и не отключает обновление ленты. |
| **Уведомления о сообщениях** | Показывает уведомление о новом сообщении, если соответствующий диалог не открыт. Применяется сразу и не останавливает обновление сообщений. |

## Фоновые воркеры

| Параметр | Диапазон и действие |
| --- | --- |
| **Потоки запросов TACTIC** | От 1 до 32 одновременных XML-RPC-запросов. Синхронизация репозитория может отправлять столько разных блоков поиска или передачи одновременно. Большое значение сильнее нагружает сервер. |
| **Локальные рабочие потоки** | От 1 до 32 одновременных локальных фоновых операций. Отдельный лимит скачивания Repository Sync не меняется. |

## Диагностика

Каждый переключатель определяет, будет ли категория записываться в Debug Log: **Лог** — общие
детали выполнения, **Информация** — штатный жизненный цикл и завершения, **Предупреждение** —
восстановимые ситуации, **Отсутствующие файлы** — неразрешённые пути, **Исключение** — перехваченные
ошибки Python и QML, **Ошибка** — невыполненные действия, **Критическая** — сбои подсистем,
**API** — диагностика вызовов TACTIC API. Отключение категории уменьшает будущий объём журнала, но
не удаляет уже записанные события.

## Расположение конфигурации

**Активный корень конфигурации** доступен только для чтения. Он показывает каталог общего API
конфигурации, чтобы поддержка могла определить активный профиль. Менять путь нужно в его владельце
окружения, а не в этом поле.
