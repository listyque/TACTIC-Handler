# Удаление sObject-объектов

> Перед удалением Delete SObject находит все серверные зависимости и сохраняет правила выбора по
> умолчанию, заданные связями TACTIC.

## Основные элементы

Окно разделяет выбранные объекты, проверку зависимостей, ошибки, прогресс и финальное действие.
Группы зависимостей используют нативные названия Search Type, семантические иконки, счётчики и
галки.

Разверните группу, чтобы просмотреть понятные названия объектов и полезные метаданные; технические
search keys остаются скрытыми. Раскрытые списки зависимостей сохраняют скруглённые края группы.

Записи журнала статусов показывают переход статуса, а затем процесс, пользователя и время вместо
технических кодов журнала.

## Как пользоваться

- Неотмеченные типы зависимостей сохраняются.
- Выбранные корневые объекты удаляются всегда.
- Удаление необратимо, выполняется вне UI-потока и после завершения обновляет исходные результаты
  или Snapshot Browser.
