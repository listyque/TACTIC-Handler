# Сборки для Windows

[English](windows_downloads.en.md)

[Скачайте Handler](https://github.com/listyque/TACTIC-Handler/releases) для Windows x64.
Setup EXE содержит Python и PySide6. Он устанавливает нативное приложение,
`TH Setup.exe` и `TH Setup Builder.exe`; системный Python не нужен.
Это предварительные сборки без цифровой подписи. Основное рабочее представление —
Item View; Perforce-подобный File Workspace остаётся прототипом.

**Clean** — настольный клиент для вашего сервера. Запустите установщик, откройте
TH Setup, укажите URL сервера, войдите и выберите проект и локальный репозиторий.
Мастер также настраивает поддерживаемые коннекторы Maya/DCC и шелф. Примените
настройки и откройте `TACTIC Handler.exe`. Выберите доступную для записи папку:
отдельный Handler хранит профиль в подпапке `TACTIC-Handler`.

**Demo** включает локальный сервер TACTIC Stream с SQLite. После установки откроется
Stream: задайте пароль администратора и войдите как `admin`. Оставьте Stream работать,
откройте TH Setup и подключитесь к `http://127.0.0.1:18881` с той же учётной записью.
Выберите Orbit Studio или Atlas Reference Library. В двух клиентах будут одни и те же
картинки, версии публикаций, задачи, пользователи и плагины. Начните с обычного
Item View: откройте Survey Drone, его задачи и публикации lookdev.

Данные демо находятся в `%APPDATA%\TACTIC Stream Demo\server`; созданные пароли
художников и читателя — в файле `demo-accounts.json` этой папки. Профиль комплектного
Handler хранится рядом, в `handler`. Профили чистой и демо-версии разделены.
Закрытие Stream останавливает локальный демо-сервер; Handler при этом может
подключаться к другому удалённому серверу через отдельный пресет.

В [релизах Stream](https://github.com/listyque/TACTIC-Stream/releases) также есть
переносимый ZIP **TH + TS**, чистый или с демо, и серверные пакеты Windows/Docker/DSM.
В [инструкции для Windows](https://github.com/listyque/TACTIC-Stream/wiki/Windows-ru)
описаны папки данных, отдельные экземпляры, сборка и восстановление.

Перед обновлением закройте приложения и сохраните копии профилей и данных сервера.
Установщик Handler сохраняет локальные настройки и файлы репозитория, оставляет
прежнюю установку в соседней папке и отказывается заменять изменённые файлы приложения.
Папка старой программы не заменяет резервную копию базы. Проверки конкретной сборки
перечислены в её релизе.
